Before performing performance optimization, you need to obtain accurate performance data to understand the current performance status and analyze the next optimization direction based on it. Ascend C provides multiple performance testing methods, including on-board Profiling and single-operator performance simulation pipeline diagrams.

## On-Board Profiling<a name="section17953123893415"></a>

The following command line is an example of collecting on-board performance data of an operator. You can flexibly combine the configuration parameters as required. In the example, **--output** is an optional parameter used to specify the storage path of the collected performance data, and **$HOME/projects/MyApp/out/main** is the operator executable file.

```
msopprof --output=$HOME/projects/output $HOME/projects/MyApp/out/main
```

## Operator Simulation Pipeline Diagram<a name="section17259539153513"></a>

The operator tuning tool msOpProf supports performance data collection and automatic parsing in the simulation environment. For details about how to use msOpProf to obtain the simulation pipeline diagram, see [msOpProf User Guide](https://gitcode.com/Ascend/msopprof/blob/26.2.0/docs/en/user_guide/msopprof_user_guide.md).

The following two visualization methods are supported:

-   Chrome browser

    In the Chrome browser, enter `chrome://tracing` in the address bar, drag the instruction pipeline diagram file (**trace.json**) generated by the msopprof simulator to the blank area, and use the keyboard shortcuts (W: zoom in, S: zoom out, A: move left, D: move right) to view it.

    ![](../../figures/zh-cn_image_0000002445425429.png)

-   The instruction pipeline diagram supports visualization in MindStudio Insight. MindStudio Insight presents the running status of instructions on Ascend AI Processors in the form of a timing diagram. By analyzing information such as instruction details, instruction execution time, call stacks of the code associated with instructions, and synchronization connections between instructions and pipelines in the timing diagram, you can identify timing optimization points of micro instructions.

    **Figure 2** Timeline interface<a name="fig1949511433715"></a>  
    ![](../../figures/timeline.png "Timeline interface")

>[!NOTE] Note 
>The operator simulation pipeline diagrams shown in some examples in this document are inconsistent with the two visualization methods described above, but the meanings of the key fields are corresponding for the two methods. For details about the meanings of specific fields, see [msOpProf User Guide](https://gitcode.com/Ascend/msopprof/blob/26.2.0/docs/en/user_guide/msopprof_user_guide.md).
