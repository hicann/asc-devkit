# Obtaining Performance Data<a name="ZH-CN_TOPIC_0000001896496393"></a>

<!-- md-trans-meta sourceCommit=195cf801df3a15b430fb9afd7dda8149cb021a63 translatedAt=2026-08-26T13:01:22.602Z -->

Before performing performance optimization, you need to obtain accurate performance data to understand the current performance status and determine the next optimization direction based on it. Ascend C provides multiple performance testing methods, including on-board Profiling and single-operator performance simulation pipeline diagrams.

## On-Board Profiling<a name="section17953123893415"></a>

The following command line is an example of collecting on-board performance data of an operator. You can flexibly combine the configuration parameters as needed. In the example, --output is an optional parameter used to specify the path for storing the collected performance data, and $HOME/projects/MyApp/out/main is the operator executable file.

```
msopprof --output=$HOME/projects/output $HOME/projects/MyApp/out/main
```

## Operator Simulation Pipeline Diagram<a name="section17259539153513"></a>

The operator tuning tool msOpProf supports performance data collection and automatic parsing in the simulation environment. For details about how to use msOpProf to obtain the simulation pipeline diagram, see [*msOpProf User Guide*](https://gitcode.com/Ascend/msopprof/blob/26.1.0/docs/en/user_guide/msopprof_user_guide.md).

The following two visualization methods are supported:

-   Chrome browser

    Enter "chrome://tracing" in the Chrome browser, drag the instruction pipeline diagram file (trace.json) generated by msopprof simulator to the blank area to open it, and use the keyboard shortcuts (W: zoom in, S: zoom out, A: move left, D: move right) to view it.

    ![](../../figures/zh-cn_image_0000002445425429.png)

-   The instruction pipeline diagram supports visualization in MindStudio Insight. MindStudio Insight presents the running status of instructions on Ascend AI Processors to users in the form of a timeline diagram. Users can identify the timing optimization points of micro instructions by analyzing the instruction details, instruction execution time, call stack of the code associated with instructions, and synchronization connections between instructions/pipelines in the timeline diagram.

    **Figure 2**  Timeline view<a name="fig1949511433715"></a>  
    ![](../../figures/timeline_view.png "Timeline view")

>[!NOTE] Note
>The operator simulation pipeline diagrams shown in some examples in this document are inconsistent with the two visualization methods described above, but the meanings of the key fields correspond to each other. Developers can refer to [*msOpProf User Guide*](https://gitcode.com/Ascend/msopprof/blob/26.1.0/docs/en/user_guide/msopprof_user_guide.md) for the meanings of specific fields.
