The high-level APIs abstract and encapsulate common algorithms based on a single core, implementing some commonly used computation algorithms to improve programming and development efficiency. High-level APIs are generally implemented by calling multiple basic APIs. High-level APIs include APIs for mathematical computation, cube computation, activation functions, and more.

As shown in the following figure, implementing a cube multiplication operation with basic APIs requires many steps and involves logic such as format conversion and data splitting. With high-level APIs, you do not need to handle such logic and can implement the function quickly.
