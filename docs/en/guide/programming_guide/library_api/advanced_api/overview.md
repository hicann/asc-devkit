The advanced API abstracts and encapsulates common algorithms based on a single core, implementing some commonly used computing algorithms to improve programming and development efficiency. The advanced API is generally implemented by calling multiple basic APIs. The advanced API includes APIs for mathematical computation, cube computation, activation functions, and more.

As shown in the following figure, implementing a cube multiplication operation using the basic API requires many steps and involves logic such as format conversion and data splitting. With the advanced API, you do not need to focus on such logic and can quickly implement the function.
