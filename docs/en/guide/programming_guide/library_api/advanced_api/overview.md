The advanced API abstracts and encapsulates common algorithms on a single core and implements some commonly used computing algorithms, aiming to improve programming and development efficiency. The advanced API is generally implemented by calling multiple basic APIs. The advanced API includes APIs for mathematical computation, cube computation, activation functions, and more.

As shown in the following figure, implementing a cube multiplication operation using the basic API requires many steps, and you need to pay attention to logic such as format conversion and data partitioning. Using the advanced API, you do not need to pay attention to this logic and can quickly implement the function.
