# What Should I Do When a File Name Overlong Error Occurs During Operator Project Compilation?<a name="ZH-CN_TOPIC_0000002072355050"></a>

## Symptoms<a name="section151611254194612"></a>

In the engineering-based operator development scenario, when performing [operator project compilation](../../advanced_programming/aclnn_operator_development/operator_package_compilation/operator_project_compilation.md), one of the following error messages is displayed:

-   file name is too long \(cannot be split\); not dumped

    ```
    ERROR: failed to create temporary archive: /tmp/mkself336430.tar
    CMake Error at /addcustom/cmake/makeself.cmake:12 (message):
      CPack Command error: 1
    
      Header is 672 lines long
    
      tar:
      ./packages/vendors/customize/op_proto/inc/my_very_long_and_detailed_c_plus_plus_project_source_code_file_containing_advanced_features_and_implementations.h:
      file name is too long (cannot be split); not dumped
    
      tar: Exiting with failure status due to previous errors
    ```

-   file name is too long \(max 256\); not dumped

    ```
    ERROR: failed to create temporary archive: /tmp/mkself133003.tar
    CMake Error at /root/r00882787/Customproj/addcustom/cmake/makeself.cmake:12 (message):
      CPack Command error: 1
    
      Header is 672 lines long
    
      tar:
      ./packages/vendors/ProjectX_FeatureY_Z_20241118_Monday_Development_BranchA1_Commit56789_AlphaVersion_ABCDEFGHIJKLM/op_impl/ai_core/tbe/ProjectX_FeatureY_Z_20241118_Monday_Development_BranchA1_Commit56789_AlphaVersion_ABCDEFGHIJKLM_impl/dynamic/add_custom.cpp:
      file name is too long (max 256); not dumped
    ```

## Root Cause<a name="section417961104715"></a>

During the build process, an error occurred when the tar command was used to package the files generated by the operator project, because the file name or path length exceeded the system limit.

## Troubleshooting<a name="section166318242419"></a>

When such an error occurs, reduce the corresponding file name length or path length based on the error message (which usually contains an overlong file name or path).

The following lists solutions to common errors:

-   File name overlong
    -   The file names of the kernel-side code in the op_kernel directory and the host-side code in the op_host directory of the operator project are automatically generated based on the OpType passed in when the operator project is created. If the error is caused by such an overlong file name, reduce the length of OpType.
    -   After the operator group name is set using the Comment API, a prototype definition code file with the same name is generated for GE to call. If the error is caused by such a file, reduce the length of the operator group name.

-   File path overlong

    When [completing the project build configuration](../../advanced_programming/aclnn_operator_development/operator_package_compilation/operator_project_compilation.md#complete-build-config), if vendor_name is configured in the CMakePresets.json file, a path named after vendor_name is generated in the vendor directory during compilation. If the error is caused by such an overlong file path, reduce the length of the configured vendor_name.
