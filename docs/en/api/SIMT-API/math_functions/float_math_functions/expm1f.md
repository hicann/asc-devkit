## Description

The header file path is `"simt_api/math_functions.h"`.

Given the input x, obtains e raised to the power of x minus 1.

![](../../../figures/formulaimage_0000002484776378.png)

## Prototype

```cpp
inline float expm1f(float x)
```

## Parameters

**Table 1**  Parameters

| Name | Input/Output | Description |
| --- | --- | --- |
| x | Input | Source operand. |

## Return Value

Returns e raised to the power of x minus 1.

-   When x is inf, returns inf.
-   When x is -inf, returns -1.0.
-   When x is nan, returns nan.

## Constraints

None

## Examples

- SIMT programming scenario:

    ```cpp
    #include "simt_api/math_functions.h"

    __global__ __launch_bounds__(256) void compute_expm1f(float *result, const float *x, uint32_t count)
    {
        const uint32_t idx = blockIdx.x * blockDim.x + threadIdx.x;
        if (idx >= count) {
            return;
        }
        result[idx] = expm1f(x[idx]);
    }
    ```

- SIMD and SIMT mixed programming scenario:

    ```cpp

    __global__ __vector__ void run_expm1f(__gm__ float *result, __gm__ const float *x, uint32_t count)
    ```
