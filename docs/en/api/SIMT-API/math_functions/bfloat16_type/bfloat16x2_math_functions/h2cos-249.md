## Description

Obtains the trigonometric cosine value of each element in the input data.

![](../../../../figures/zh-cn_formulaimage_0000002545900882.png)

## Function Prototype

```
inline bfloat16x2_t h2cos(bfloat16x2_t x)
```

## Parameters

**Table 1**  Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| x | Input | Source operand. |

## Return Value

Returns the trigonometric cosine value of each element in the input data.

-   When the input element is inf, the return value is nan.
-   When the input element is -inf, the return value is nan.
-   When the input element is nan, the return value is nan.

## Constraints

None

## Header Files to Include

To use the bfloat16x2\_t interface, include the "simt\_api/asc\_bf16.h" header file.

```
#include "simt_api/asc_bf16.h"
```
