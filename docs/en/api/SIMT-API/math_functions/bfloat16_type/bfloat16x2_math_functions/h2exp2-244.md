# h2exp2

## Applicable Products

- Ascend 950PR/Ascend 950DT: Supported
- Atlas A3 training products/Atlas A3 inference products: Not supported

- Atlas 200I/500 A2 inference product: Not supported

- Atlas inference products Vector Core: Not supported
- Atlas training products: Not supported

## Description

For a given input **x**, computes 2 raised to the power of each element of **x**.

![](../../../../figures/zh-cn_formulaimage_0000002576421061.png)

## Function Prototype

```
inline bfloat16x2_t h2exp2(bfloat16x2_t x)
```

## Parameters

**Table 1**  Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| x | Input | Source operand. |

## Return Value

Returns each input element raised to the power of 2.

-   When the input element is inf, the return value is inf.
-   When the input element is -inf, the return value is 0.
-   When the input element is nan, the return value is nan.
-   When the result exceeds the maximum range of float, the return value is inf.

## Constraints

<!-- npu="950" id7 -->
For Ascend 950PR/Ascend 950DT, this API does not support the Subnormal scenario: input and output values within the Subnormal range are flushed to zero with the sign preserved.
<!-- end id7 -->

## Header Files to Include

To use the `bfloat16x2_t` interface, include the "simt_api/asc_bf16.h" header file.

```
#include "simt_api/asc_bf16.h"
```

## Example

-   SIMT programming scenario:

    ```
    __global__ __launch_bounds__(1024) void KernelExp2(bfloat16x2_t* dst, bfloat16x2_t* x)
    {
        int idx = threadIdx.x + blockIdx.x * blockDim.x;
        dst[idx] = h2exp2(x[idx]);
    }
    ```

-   SIMD and SIMT hybrid programming scenario:

    ```
    __simt_vf__ __launch_bounds__(1024) inline void KernelExp2(__gm__ bfloat16x2_t* dst, __gm__ bfloat16x2_t* x)
    {
        int idx = threadIdx.x + blockIdx.x * blockDim.x;
        dst[idx] = h2exp2(x[idx]);
    }
    ```
