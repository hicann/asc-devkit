## Description

Obtains the natural logarithm (base e) of each element of the input data.

![](../../../../figures/zh-cn_formulaimage_0000002576421063.png)

## Function Prototype

```
inline bfloat16x2_t h2log(bfloat16x2_t x)
```

## Parameters

**Table 1**  Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| x | Input | Source operand. |

## Return Value

The natural logarithm (base e) of each element of the input data.

-   When the input element is less than 0 or is nan, the return value is nan.
-   When the input element is 0, the return value is -inf.
-   When the input element is inf, the return value is inf.

## Constraints

None

## Header Files to Include

To use the bfloat16x2\_t interface, include the "simt\_api/asc\_bf16.h" header file.

```
#include "simt_api/asc_bf16.h"
```
