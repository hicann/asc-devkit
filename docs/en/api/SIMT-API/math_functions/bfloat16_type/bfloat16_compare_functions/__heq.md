## Description

The header file path is: `"simt_api/asc_bf16.h"`.

Compares whether two bfloat16 data are equal, and returns true if they are equal.

## Prototype

```cpp
bool __heq(bfloat16_t x, bfloat16_t y)
```

## Parameters

**Table 1**  Parameters

| Name | Input/Output | Description |
| --- | --- | --- |
| x | Input | Source operand. |
| y | Input | Source operand. |

## Return Value

Returns the result of whether the input data are equal.

-   **true**: The input data are equal.
-   false: The input data are not equal, or either input is nan.

## Constraints

None
