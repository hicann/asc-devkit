## Description

The header file path is: `"simt_api/asc_fp16.h"`.

Checks whether the two components of a half2 value are nan.

## Prototype

```cpp
half2 __isnanx2(half2 x)
```

## Parameters

**Table 1**  Parameters

| Name | Input/Output | Description |
| --- | --- | --- |
| x | Input | Source operand. |

## Return Value

Returns the result of checking whether each component of the input data is nan. If a component is nan, the corresponding result is 1; otherwise, it is 0. The special values are as follows:

| Input | Return Value |
| --- | --- |
| nan | 1 |
| ±0 | 0 |
| ±inf | 0 |
| ASCRT\_MAX\_NORMAL\_FP16 | 0 |

## Constraints

None

## Examples

-   SIMT programming scenario:

    ```cpp
    #include "simt_api/asc_fp16.h"

    // Use short vectors to improve data transfer efficiency.
    __global__ __launch_bounds__(1024) void simt_isnanx2(half* x, half* dst, uint32_t input_total_length)
    {
        uint32_t idx = blockIdx.x * blockDim.x + threadIdx.x;
        // Each thread processes one half2 value, that is, two half values. Therefore, threads with idx >= input_total_length / 2 do not process data.
        if (idx >= input_total_length / 2) {
            return;
        }
        half2* input = (half2*)x;
        half2* out = (half2*)dst;
        out[idx] = __isnanx2(input[idx]);
    }
    ```
