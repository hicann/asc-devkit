## Description

Obtains the total number of threads in the `thread_block_tile` group to which the current thread belongs.

## Function Prototype

```c++
unsigned long long num_threads() const
```

## Parameters

None

## Return Value

Returns the total number of threads in the `thread_block_tile` group to which the current thread belongs.

## Constraints

None

## Example

- SIMT programming scenario:

    ```c++
    using namespace cooperative_groups;
    __global__ void simt_kernel(...)
    {
        ...
        thread_block block = this_thread_block();
        auto tile4 = tiled_partition<4>(block);
        unsigned long long thread_num = tile4.num_threads();    // Returns 4.
        ...
    }
    ```

- SIMD and SIMT hybrid programming scenario:

    ```c++
    using namespace cooperative_groups;
    __simt_vf__ inline void simt_kernel(...)
    {
        ...

        ...
    ```
