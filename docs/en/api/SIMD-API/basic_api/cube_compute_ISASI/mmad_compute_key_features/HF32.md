# HF32<a name="ZH-CN_TOPIC_0000002538231188"></a>

<!-- md-trans-meta sourceCommit=754fb95859dead826727a591e674261c6a829a08 translatedAt=2026-09-23T13:32:17.016Z pushedAt=2026-10-26T07:41:44.198Z nl=2 -->

**Description:**

The core function of HF32 is as follows: when the input matrices A and B are both of the fp32 data type, and the HF32 switch is enabled, the fp32 data is converted and rounded to the HF32 (half-fp32) format before the matrix multiplication is performed. This approach improves the computational performance of the Mmad (f322f32) API, but introduces a certain degree of precision loss. Note that although the intermediate computation uses the HF32 format, the final result is still output in the fp32 format to ensure compatibility with subsequent processing.

The impact of enabling HF32 on performance is as follows:

<!-- npu="A3,910b" id3 -->
- For the following product models:

  <!-- npu="A3" id4 -->
  Atlas A3 products
  <!-- end id4 -->
  <!-- npu="910b" id5 -->
  Atlas A2 products
  <!-- end id5 -->
Enabling HF32 can double the computational performance of the Mmad (f322f32) API.
<!-- end id3 -->

<!-- npu="950" id2 -->
- For the Ascend 950PR&950DT products, enabling HF32 can improve the computational performance of the Mmad (f322f32) API by eight times.
<!-- end id2 -->

Rounding mode description: The rounding mode used in the fp32-to-HF32 conversion is configured through the [SetHF32TransMode](../mmad_compute_aux_config/SetHF32TransMode.md) API. When HF32 mode is enabled and TransMode is set to NEAREST_AWAY, FP32 is rounded to HF32 by rounding to the nearest value, with ties rounded away from zero. When TransMode is set to NEAREST_EVEN, FP32 is rounded to HF32 by rounding to the nearest value, with ties rounded to even.

**Example:**

```cpp
// Enable the HF32 mode.
AscendC::SetHF32Mode(AscendC::HF32Mode::ENABLE);
// Set the rounding mode to round to the nearest value, with ties rounding away from zero, to convert to HF32.
AscendC::SetHF32TransMode(AscendC::HF32TransMode::NEAREST_AWAY);
AscendC::MmadParams mmadParams;
mmadParams.m = m;
mmadParams.n = n;
mmadParams.k = k;
AscendC::Mmad(c1Local, a2Local, b2Local, mmadParams);
AscendC::SetHF32Mode(AscendC::HF32Mode::DISABLE);
AscendC::SetHF32TransMode(AscendC::HF32TransMode::NEAREST_EVEN);
```
