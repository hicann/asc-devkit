# HF32<a name="ZH-CN_TOPIC_0000002538231188"></a>

<!-- md-trans-meta sourceCommit=e9bec8b34ada6c37c20391d212da5ebf088e2e8b translatedAt=2026-08-27T17:03:31.061Z -->

**Description:**

The core function of HF32 is as follows: In the scenario where both input matrices A and B are of the fp32 data type, when the HF32 switch is enabled, the fp32 data is converted and rounded to the HF32 (half-fp32) format before the cube multiplication operation is performed. This approach doubles the computational performance of the **Mmad (f322f32)** API, but introduces a certain loss of precision. Note that although the intermediate computation uses the HF32 format, the final result is still output in the fp32 format to ensure compatibility with subsequent processing.

Rounding mode description: The rounding mode used during the fp32-to-HF32 conversion is configured through the **SetHF32TransMode** API. When the HF32 mode is enabled and **TransMode** is set to **NEAREST_ZERO**, fp32 is rounded to HF32 toward zero. When **TransMode** is set to **NEAREST_EVEN**, fp32 is rounded to HF32 toward the nearest even value.

**Example:**

```cpp
// Enable HF32 mode.
AscendC::SetHF32Mode(AscendC::HF32Mode::ENABLE);
// Set the conversion mode to round toward zero.
AscendC::SetHF32TransMode(AscendC::HF32TransMode::NEAREST_ZERO);
AscendC::MmadParams mmadParams;
mmadParams.m = m;
mmadParams.n = n;
mmadParams.k = k;
AscendC::Mmad(c1Local, a2Local, b2Local, mmadParams);
AscendC::SetHF32Mode(AscendC::HF32Mode::DISABLE);
AscendC::SetHF32TransMode(AscendC::HF32TransMode::NEAREST_EVEN);
```
