## Description<a name="section618mcpsimp"></a>

Sets the buffer length. When a user calls the operator\[\] function to create a new **LocalTensor**, it is recommended to call this API to set the length of the new **LocalTensor**, so that the compiler can automatically optimize memory and synchronization.

## Prototype<a name="section620mcpsimp"></a>

```cpp
__aicore__ inline void SetBufferLen(uint32_t dataLen)
```
