## Function Description<a name="zh-cn_topic_0000001526206862_section212607105720"></a>

When using this macro, developers can obtain the corresponding Tiling information by specifying a structure name and fill it into the corresponding Tiling structure. After the filling is complete, this macro returns a pointer to the Tiling structure and modifies the pointer with the \_\_tiling\_data\_ptr\_\_ modifier. This modification ensures code consistency and compatibility in both dynamic and static Shape scenarios.

## Prototype<a name="zh-cn_topic_0000001526206862_section1630753514297"></a>

```
GET_TILING_DATA_PTR_WITH_STRUCT(tiling_struct, dst_ptr, tiling_ptr)
```

## Constraints<a name="zh-cn_topic_0000001526206862_section65498832"></a>

-   This macro must be used in the operator kernel function (Kernel) code, and the passed-in dst\_ptr parameter does not require a type declaration.
-   In the dynamic Shape scenario, the obtained dst\_ptr is a pointer to a Global Memory variable; in the static Shape scenario, the obtained dst\_ptr is a pointer to a local variable, and it must be ensured that it is used within a reasonable scope.
-   The kernel function (Kernel) direct invocation project is not supported.

## Example<a name="zh-cn_topic_0000001526206862_section97001499599"></a>

```
extern "C" __global__ __aicore__ void add_custom(__gm__ uint8_t *x, __gm__ uint8_t *y, __gm__ uint8_t *z, __gm__ uint8_t *tiling)
{
    KernelAdd op;

    GET_TILING_DATA_PTR_WITH_STRUCT(AddCustomTilingData, tilingDataPtr, tiling);

    op.Init(x, y, z, tilingDataPtr->totalLength, tilingDataPtr->tileNum);
    op.Process();
    
}
```

The following is an example of an incorrect call:

```
__aicore__ __tiling_data_ptr__ AddCustomTilingData* foo(__gm__ uint8_t *tiling)
{
    GET_TILING_DATA_PTR_WITH_STRUCT(AddCustomTilingData, tilingDataPtr, tiling);
    return tilingDataPtr;
}

extern "C" __global__ __aicore__ void add_custom(__gm__ uint8_t *x, __gm__ uint8_t *y, __gm__ uint8_t *z, __gm__ uint8_t *tiling)
{
    KernelAdd op;

    auto tilingDataPtr = foo(tiling);  // Error: the foo function has completed execution, and a local variable whose lifetime has ended is illegally accessed.

    op.Init(x, y, z, tilingDataPtr->totalLength, tilingDataPtr->tileNum);
    op.Process();
}
```
