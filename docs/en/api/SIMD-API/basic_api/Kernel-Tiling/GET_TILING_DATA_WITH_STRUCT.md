## Description<a name="zh-cn_topic_0000001526206862_section212607105720"></a>

This API specifies a structure name to obtain the corresponding tiling information and fill it into the corresponding Tiling structure. This function is compiled through macro expansion. The difference from [GET_TILING_DATA](GET_TILING_DATA.md) is that [GET_TILING_DATA](GET_TILING_DATA.md) can only obtain the structure registered by default, whereas this API can obtain the corresponding structure based on the specified structure name. It is commonly used when different structures are registered for different TilingKeys.

## Prototype<a name="zh-cn_topic_0000001526206862_section1630753514297"></a>

```
GET_TILING_DATA_WITH_STRUCT(struct_name, tiling_data, tiling_arg)
```

## Constraints<a name="zh-cn_topic_0000001526206862_section65498832"></a>

-   This function must be used in the operator Kernel code, and the passed `tiling_data` parameter does not need to declare a type.
-   Kernel direct invocation projects are not supported.

## Example<a name="zh-cn_topic_0000001526206862_section97001499599"></a>

```
extern "C" __global__ __aicore__ void add_custom(__gm__ uint8_t *x, __gm__ uint8_t *y, __gm__ uint8_t *z, __gm__ uint8_t *tiling)
{
    KernelAdd op;
    if (TILING_KEY_IS(1)) {
        GET_TILING_DATA_WITH_STRUCT(Add_Struct_Special, tilingData, tiling); // Use the structure registered by the operator.
	op.Init(x, y, z, tilingData.totalLengthSpecial, tilingData.tileNumSpecial);
    } else {
        GET_TILING_DATA(tilingData, tiling);   // Use the structure registered by default for the operator.
	op.Init(x, y, z, tilingData.totalLength, tilingData.tileNum);
    }
    if (TILING_KEY_IS(1)) {
        op.Process();
    }  else  if (TILING_KEY_IS(2)) {
        op.Process();
    } else  if (TILING_KEY_IS(3)) {
        op.Process();
    }
}
```
