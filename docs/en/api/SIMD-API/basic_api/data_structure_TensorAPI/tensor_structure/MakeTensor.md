## Description

The header file to include is: `#include "tensor_api/tensor.h"`.

**MakeTensor** binds a memory pointer (generated by [MakeMemPtr](MakeMemPtr.md)) with a layout object (generated by [MakeFrameLayout](../layout_structure/MakeFrameLayout.md)/[MakeLayout](../layout_structure/MakeLayout.md)) to produce a Tensor object with complete type information.

**MakeTensor** automatically derives and returns a **GlobalTensor** or **LocalTensor** based on the physical location marker of the memory pointer. When the pointer is located in Global Memory (external storage), it returns a **GlobalTensor**; when the pointer is located in Local Memory (internal storage) on the AI Core, it returns a **LocalTensor**.

The generated Tensor object can be passed directly to APIs such as Copy (data movement) and Mmad (cube computation). The compiler automatically selects the underlying hardware instructions based on the physical location marker in its Engine and the layout mode in its Layout.

## Prototype

```cpp
template <typename Iterator, typename... Args>
__aicore__ inline constexpr auto MakeTensor(const Iterator& iter, const Args&... args)
```

## Parameters

| Parameter  | Input/Output | Description |
| :----- | :------- | :------- |
| iter | Input | Iterator. A **ViewEngine** object is required to create a **Tensor**. The return type is determined by the memory location bound to this iterator. |
| args | Input | Variadic parameters. Currently, one or two parameters are supported.<br>&bull;When one parameter is passed: Creates a **Tensor** based on the passed **Layout** object.<br>&bull;When two parameters are passed: Constructs a **Layout** object based on the passed parameters, and creates a **Tensor** based on that **Layout**. |

## Return Value

- Returns a tensor object of the **GlobalTensor**<**TensorAttribute**<**Engine**, **Layout**>> or **LocalTensor**<**TensorAttribute**<**Engine**, **Layout**>> type, depending on the memory location bound to **Engine**.

## Example

  ```cpp
  // Example 1: Create a GlobalTensor using a GM pointer and Layout.
  auto gmPtr = MakeMemPtr<Location::GM, half>(gmAddr);
  auto gmLayout = MakeLayout(MakeShape(32, 32), MakeStride(32, 1));
  auto gmTensor = MakeTensor(gmPtr, gmLayout);

  // Example 2: Create a LocalTensor using a Local Memory pointer and Layout.
  constexpr int tileNum = 4;
  __cbuf__ half dataPtr[tileNum]; // Initialize.
  auto ptr = MakeMemPtr(dataPtr);
  auto layout = MakeFrameLayout<NZLayoutPtn, half>(32, 32);
  auto tensor = MakeTensor(ptr, layout);
  
  // Example 3: Create a tensor using a pointer and layout shape.
  auto tensor2 = MakeTensor(ptr, MakeShape(32, 32), MakeStride(32, 32));
  ```
