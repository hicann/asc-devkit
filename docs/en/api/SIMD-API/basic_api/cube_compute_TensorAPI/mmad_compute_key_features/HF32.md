# HF32

<!-- md-trans-meta sourceCommit=e9bec8b34ada6c37c20391d212da5ebf088e2e8b translatedAt=2026-08-27T17:27:42.347Z -->

## Description

The core function of HF32 is as follows: when both input matrices A and B are of the `fp32` data type, after the HF32 switch is enabled, the `fp32` data is converted and rounded to the HF32 (half-fp32) format before the cube multiplication operation is performed. This approach can double the computing performance of the [`Mmad`](../Mmad computing/Mmad.md) (`fp32`->`fp32`) API, but it introduces a certain degree of precision loss. Note that although the intermediate computation uses the HF32 format, the final operation result is still output in the `fp32` format to ensure compatibility with subsequent processing.

> **Note:** Enabling HF32 introduces precision loss. The `fp32` input data is converted and rounded to the HF32 format before the cube multiplication operation.

Rounding mode description: The rounding mode used in the `fp32`-to-`HF32` conversion is configured through the [`SetHF32TransMode`](../../cube_compute_ISASI/mmad_compute_aux_config/SetHF32TransMode.md) API. When the `HF32` mode is enabled and `TransMode` is set to `HF32TransMode::NEAREST_ZERO`, `FP32` is rounded to `HF32` toward zero. When `TransMode` is set to `HF32TransMode::NEAREST_EVEN`, `FP32` is rounded to `HF32` to the nearest even.

## Constraints

- HF32 applies to the `Mmad` (`fp32`->`fp32`) scenario where both input matrices A and B are of the `fp32` data type.
- Before using the HF32 mode, enable it through [SetHF32Mode](../../cube_compute_ISASI/mmad_compute_aux_config/SetHF32Mode.md). The rounding mode used during the `fp32`-to-HF32 conversion is configured through [SetHF32TransMode](../../cube_compute_ISASI/mmad_compute_aux_config/SetHF32TransMode.md).

## Example

Use [SetHF32Mode](../../cube_compute_ISASI/mmad_compute_aux_config/SetHF32Mode.md) to enable or disable HF32 mode, and use [SetHF32TransMode](../../cube_compute_ISASI/mmad_compute_aux_config/SetHF32TransMode.md) to configure the rounding mode.

```cpp
using namespace AscendC::Te;

// Enable HF32 mode.
AscendC::SetHF32Mode(AscendC::HF32Mode::ENABLE);
// Set the conversion mode to round toward zero.
AscendC::SetHF32TransMode(AscendC::HF32TransMode::NEAREST_ZERO);

// Mmad computation code.
MmadParams params(m, n, k, 0, true);
auto atom = MakeMmad(MmadOperation{}, MmadTraitDefault{}).with(params);
Mmad(atom, l0C, l0A, l0B);

// Disable HF32 mode.
AscendC::SetHF32Mode(AscendC::HF32Mode::DISABLE);
AscendC::SetHF32TransMode(AscendC::HF32TransMode::NEAREST_EVEN);
```
