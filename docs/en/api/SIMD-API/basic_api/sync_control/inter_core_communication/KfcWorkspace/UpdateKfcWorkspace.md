## Function Description<a name="zh-cn_topic_0000001526206862_section212607105720"></a>

Updates the memory address used for the CubeResGroupHandle message communication area. When using the [CubeResGroupHandle](../../inter_core_communication/CubeResGroupHandle/CubeResGroupHandle_constructor.md) API, this API must be used to manage the space address independently.

## Prototype<a name="section765814724715"></a>

```
__aicore__ inline void UpdateKfcWorkspace(uint32_t offset)
```

## Constraints<a name="zh-cn_topic_0000001526206862_section65498832"></a>
