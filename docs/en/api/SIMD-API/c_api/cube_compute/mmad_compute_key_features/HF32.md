# HF32

<!-- md-trans-meta sourceCommit=54f1d966cfcc22290ddc2c6312bbe4c6ac2a9232 translatedAt=2026-11-16T10:21:32.635Z pushedAt=2026-11-18T08:15:34.231Z nl=2 -->

**Feature Description:**

The core function of HF32 is as follows: when both input cubes A and B are of the fp32 data type, after the HF32 switch is enabled, the fp32 data is converted and rounded to the HF32 (half-fp32) format before the cube multiplication operation is performed. This approach improves the computational performance of Mmad-type (f322f32) interfaces, but introduces a certain loss of numeric precision. Note that although the intermediate computation uses the HF32 format, the final operation result is still output in the fp32 format to ensure compatibility with subsequent processing.

The impact of enabling HF32 on performance is as follows:

<!-- npu="A3,910b" id3 -->
- For the following product models:

  <!-- npu="A3" id4 -->
  Atlas A3 products
  <!-- end id4 -->
  <!-- npu="910b" id5 -->
  Atlas A2 products
  <!-- end id5 -->
  Enabling HF32 can improve the computational performance of Mmad-type (f322f32) interfaces to twice the original performance.
<!-- end id3 -->

<!-- npu="950" id2 -->
- For Ascend 950PR&950DT products, enabling HF32 can improve the computational performance of Mmad (f322f32) interfaces to eight times the original.
<!-- end id2 -->

Rounding mode description: the rounding mode used in the fp32-to-HF32 conversion is configured by the [asc_set_hf32_round_mode](../mmad_compute_aux_config/asc_set_hf32_round_mode.md) interface. When HF32 mode is enabled and asc_hf32_round_mode is set to NEAREST_AWAY, FP32 is rounded to HF32 by rounding to the nearest value, with ties rounded away from zero. When asc_hf32_round_mode is set to NEAREST_EVEN, FP32 is rounded to HF32 by rounding to the nearest value, with ties rounded to the nearest even value.

Use [asc_enable_hf32](../mmad_compute_aux_config/asc_enable_hf32.md) to enable HF32 mode, and use [asc_disable_hf32](../mmad_compute_aux_config/asc_disable_hf32.md) to disable it. For the compute interface and input type requirements, see [asc_mmad](../mmad_compute/asc_mmad.md).

**Usage example:**

```cpp
// Enable HF32 mode.
asc_enable_hf32();
asc_set_hf32_round_mode(asc_hf32_round_mode::NEAREST_AWAY);
asc_mmad(c, a, b, m, k, n, asc_unit_flag_mode::DISABLE,
         false, false, true);
// Disable HF32 mode and restore the default rounding mode.
asc_disable_hf32();
asc_set_hf32_round_mode(asc_hf32_round_mode::NEAREST_EVEN);
```
