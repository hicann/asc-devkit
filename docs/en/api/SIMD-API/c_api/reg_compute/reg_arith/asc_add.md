## Description

The header file path is `"c_api/reg_compute/compute/reg_arith.h"`.

This API performs an element-wise sum operation on the source operands `src0` and `src1` based on `mask`, and writes the result to the destination operand `dst`.

The carry flag is used to indicate an addition carry or no borrow in subtraction. This API can mark in `carry` (mask register) whether each addition generates a carry. If the highest bit has a carry after the bitwise addition of `src0` and `src1`, 1 is written to the lowest bit of each 4-bit group at the corresponding position in `carry`; otherwise, 0 is written.

**[Addition Without Carry Output](#addition-without-carry-output)**: Single destination operand. The vector data register is written with the addition sum. The calculation formula is as follows:

$$
dst_i = src0_i + src1_i
$$

**[Addition with Carry Output](#addition-with-carry-output)**: Dual destination operands. During hardware computation, the inputs are processed as 32-bit unsigned numbers. The vector data register is written with the lower 32 bits of the addition sum, and the destination mask register is written with the carry output generated by the addition of each element. The calculation formula is as follows:

$$
\{carry_i, dst_i\} = \{1'b0, src0_i\} + \{1'b0, src1_i\}
$$

![](../../../../figures/asc_add.png)

For applicable scenarios of the output `carry`, see [asc_addc Description](asc_addc.md#description).

This API is a Reg vector computation API and takes effect only on AIV.

## Parameters

### Addition Without Carry Output

**Table 1** Parameters

| Parameter | Input/Output | Description |
|---|---|---|
| dst | Output | Destination operand (vector data register), used to store the addition sum. |
| src0 | Input | Source operand (vector data register). |
| src1 | Input | Source operand (vector data register). |
| mask | Input | Source operand mask (mask register), which indicates which elements participate in the computation. **Table 2** Parameters

| Parameter | Input/Output | Description |
|---|---|---|

| src0 | Input | Source operand (vector data register). |
| src1 | Input | Source operand (vector data register). |
| mask | Input | Source operand mask (mask register). Indicates which elements participate in the computation. Elements at positions where the corresponding bit is 1 participate in the computation, and elements at positions where the corresponding bit is 0 do not. Elements not selected by mask are set to zero in the output. |

## Return Value

- The prototype that outputs the result through a reference parameter has no return value.
- The prototype that outputs the result through the function return value returns the addition result without carry, and the return value type is the same as the source operand type.
- Addition with carry output supports only outputting the result through a reference parameter and has no return value.

## Constraints

### General Constraints

- For the general constraints on Reg vector computation C APIs, see [General Constraints](../overview.md#general-constraints).

### Constraints for Addition Without Carry Output

- For integer dtype addition, overflow is handled using the wrap-around policy: signed types wrap around to the minimum or maximum value of the corresponding dtype (MAX+1->MIN, MIN-1->MAX), and unsigned types wrap around to 0 (UMAX+1->0).
- For floating-point dtype (half, bfloat16_t, float) addition, the operation follows IEEE 754 floating-point addition semantics, and overflow and invalid inputs (such as nan and inf) are handled according to floating-point arithmetic rules.

### Constraints for Addition with Carry Output

- The operation outputs the complete computation result (including the carry bit), which is not affected by [asc_set_ctrl](../../spr/asc_set_ctrl.md), and the hardware does not saturate or truncate the output.
- The carry output is generated according to 32-bit unsigned addition: the carry of each element is the highest 1 bit of `(src0_i + src1_i) >> 32`.
- The sum is truncated to 32 bits: `dst` writes `(src0_i + src1_i) & 0xFFFFFFFF`, and the portion exceeding 32 bits is not retained, being reflected only through the carry output of `carry`.

```c
#include <cstdint>
#include <iostream>
#include <vector>

#include "c_api/asc_simd.h"
#include "utils/std/cmath.h"
#include "acl/acl.h"

namespace {
template <typename T>
void print_data(const char* label, const std::vector<T>& values)
{
    std::cout << label << ":";
    const size_t count = values.size() < 8 ? values.size() : 8;
    for (size_t i = 0; i < count; ++i) std::cout << ' ' << +values[i];
    if (values.size() > count) std::cout << " ...";
    std::cout << std::endl;
}

template <typename T>
bool compare_data(const std::vector<T>& actual, const std::vector<T>& expected)
{
    return actual == expected;
}

// Reserve UB space based on the 256-byte register width. Each register holds 256 / sizeof(int32_t) = 64 elements.
constexpr uint32_t ELEMENTS_PER_REGISTER = 64;
// Use 137 valid elements to cover two full registers and a tail block with only 9 valid elements.
constexpr uint32_t DATA_BYTES = 137 * sizeof(int32_t);
// Convert the byte count to an element count for calculating the iteration count and valid-element mask.
constexpr uint32_t TOTAL_LENGTH = DATA_BYTES / sizeof(int32_t);
// Round up to obtain 3 register blocks; integer division yields only 2 and would leave the tail block unprocessed.
constexpr uint32_t REPEAT_COUNT =
    (TOTAL_LENGTH + ELEMENTS_PER_REGISTER - 1) / ELEMENTS_PER_REGISTER;
// Extend UB capacity to 3 * 64 = 192 elements so that full-register loads in the final iteration stay within the allocated space.
// The extra space is only for safe loads; the mask and TOTAL_LENGTH still control the valid range for computation and writeback.
constexpr uint32_t PADDED_ELEMENT_COUNT = REPEAT_COUNT * ELEMENTS_PER_REGISTER;
constexpr uint8_t MUTEX_ID = 0;

__simd_vf__ inline void add_vf(__ubuf__ int32_t* dst, __ubuf__ int32_t* src0, __ubuf__ int32_t* src1, uint32_t one_repeat_size, uint16_t repeat_time)
{
    vector_int32_t dst_reg;
    vector_int32_t src0_reg;
    vector_int32_t src1_reg;
    // Record the number of valid elements remaining, which asc_update_mask_b32 decrements on each iteration.
    uint32_t remaining_length = TOTAL_LENGTH;
    for (uint16_t i = 0; i < repeat_time; ++i) {
        // Advance by one register block on each iteration. The unit of offset is int32_t elements, rather than bytes.
        const uint32_t offset = i * one_repeat_size;
        // Enable 64, 64, and 9 elements in the three iterations, respectively; only the first 9 valid elements are computed and stored in the final iteration.
        vector_bool mask = asc_update_mask_b32(remaining_length);
        asc_loadalign(src0_reg, src0 + offset);
        asc_loadalign(src1_reg, src1 + offset);
        asc_add(dst_reg, src0_reg, src1_reg, mask);
        asc_storealign(dst + offset, dst_reg, mask);
    }
}

__global__ __vector__ void asc_add_kernel(__gm__ int32_t* dst, __gm__ int32_t* src0, __gm__ int32_t* src1)
{
    asc_init();
    __ubuf__ int32_t dst_local[PADDED_ELEMENT_COUNT];
    __ubuf__ int32_t src0_local[PADDED_ELEMENT_COUNT];
    __ubuf__ int32_t src1_local[PADDED_ELEMENT_COUNT];

    asc_lock(PIPE_MTE2, MUTEX_ID);
    asc_copy_gm2ub_align(src0_local, src0, TOTAL_LENGTH * sizeof(int32_t));
    asc_copy_gm2ub_align(src1_local, src1, TOTAL_LENGTH * sizeof(int32_t));
    asc_unlock(PIPE_MTE2, MUTEX_ID);

    // asc_get_vf_len returns a byte count. Divide it by the element size in bytes to obtain the number of elements processed per iteration (64 in this example).
    uint32_t one_repeat_size = static_cast<uint32_t>(asc_get_vf_len() / sizeof(int32_t));
    // Round up based on the actual per-iteration capacity: ceil(137 / 64) = 3, ensuring that the last 9 elements are also processed.
    uint16_t repeat_time = static_cast<uint16_t>(AscendC::Std::ceil_div(TOTAL_LENGTH, one_repeat_size));
    asc_lock(PIPE_V, MUTEX_ID);
    asc_vf_call<add_vf>(dst_local, src0_local, src1_local, one_repeat_size, repeat_time);
    asc_unlock(PIPE_V, MUTEX_ID);

    asc_lock(PIPE_MTE3, MUTEX_ID);
    // Store only 137 valid elements; do not write the extra UB space reserved for full-register loads to GM.
    asc_copy_ub2gm_align(dst, dst_local, TOTAL_LENGTH * sizeof(int32_t));
    asc_unlock(PIPE_MTE3, MUTEX_ID);
    asc_sync();
}

} // namespace

int main()
{
    std::vector<int32_t> src0(TOTAL_LENGTH);
    std::vector<int32_t> src1(TOTAL_LENGTH);
    std::vector<int32_t> output(TOTAL_LENGTH, 0);
    std::vector<int32_t> golden(TOTAL_LENGTH);

    for (uint32_t i = 0; i < TOTAL_LENGTH; ++i) {
        src0[i] = static_cast<int32_t>(i) - 64;
        src1[i] = static_cast<int32_t>(TOTAL_LENGTH - i);
        golden[i] = src0[i] + src1[i];
    }

    aclInit(nullptr);
    aclrtSetDevice(0);
    int32_t* src0_device = nullptr;
    aclrtMalloc(reinterpret_cast<void**>(&src0_device), (TOTAL_LENGTH) * sizeof(int32_t),
        ACL_MEM_MALLOC_HUGE_FIRST);
    int32_t* src1_device = nullptr;
    aclrtMalloc(reinterpret_cast<void**>(&src1_device), (TOTAL_LENGTH) * sizeof(int32_t),
        ACL_MEM_MALLOC_HUGE_FIRST);
    int32_t* dst_device = nullptr;
    aclrtMalloc(reinterpret_cast<void**>(&dst_device), (TOTAL_LENGTH) * sizeof(int32_t),
        ACL_MEM_MALLOC_HUGE_FIRST);
    aclrtMemcpy(src0_device, src0.size() * sizeof(int32_t), src0.data(), src0.size() * sizeof(int32_t),
        ACL_MEMCPY_HOST_TO_DEVICE);
    aclrtMemcpy(src1_device, src1.size() * sizeof(int32_t), src1.data(), src1.size() * sizeof(int32_t),
        ACL_MEMCPY_HOST_TO_DEVICE);

    asc_add_kernel<<<1, 0>>>(dst_device, src0_device, src1_device);
    aclrtSynchronizeDevice();
    aclrtMemcpy(output.data(), output.size() * sizeof(int32_t), dst_device, output.size() * sizeof(int32_t),
        ACL_MEMCPY_DEVICE_TO_HOST);

    print_data("Input src0", src0);
    print_data("Input src1", src1);
    print_data("Output", output);
    print_data("Golden", golden);
    const bool passed = compare_data(output, golden);
    std::cout << (passed ? "[Success] asc_add passed." : "[Failed] asc_add failed.") << std::endl;
    aclrtFree(dst_device);
    aclrtFree(src0_device);
    aclrtFree(src1_device);
    aclrtResetDevice(0);
    aclFinalize();
    return passed ? 0 : 1;
}
```
