# ASC_DEPRECATED

<!-- md-trans-meta sourceCommit=54f1d966cfcc22290ddc2c6312bbe4c6ac2a9232 translatedAt=2026-11-16T12:14:49.984Z pushedAt=2026-11-18T08:15:34.408Z nl=2 -->

## Description

The header file path is: `"c_api/defs/macro.h"`.

`ASC_DEPRECATED` is used to add the C++ `[[deprecated]]` attribute to C API declarations. When developers compile code that calls the marked API, the compiler generates a warning containing the version in which the API began to be deprecated, the planned removal date, and the recommended replacement API.

This macro only adds the deprecation attribute and warning information. It does not prevent the marked API from participating in compilation, nor does it automatically remove the API after the planned removal date.

## Macro Definition

```cpp
#define ASC_DEPRECATED(version, removal_date, replacement)                                                  \
    [[deprecated("Deprecated since " #version ", Will be removed after " removal_date ", Use " #replacement \
                 " instead.")]]
```

## Parameters

**Table 1** Parameter description

| Parameter | Description |
| --- | --- |
| version | CANN version number at which the interface starts to be deprecated. The macro converts this parameter to a string, so do not add double quotes when passing it, for example, `9.2.0`. |
| removal_date | Planned removal date of the interface. This parameter must be in string form with the format `"YYYY/MM/DD"`, for example, `"2027/09/07"`. |
| replacement | Recommended replacement interface or alternative solution. The macro converts this parameter to a string, so do not add double quotes when passing it; when there are multiple replacement interfaces, you can pass a complete description of the alternative solution. |

The format of the compilation warning message is as follows:

```text
Deprecated since <version>, Will be removed after <removal_date>, Use <replacement> instead.
```

## Constraints

- When using this macro, place it before the declaration that needs to be marked as deprecated.
- `version` and `replacement` are converted to strings through the preprocessor `#` operator, so double quotes should not be added to these parameters; `removal_date` is directly concatenated into the warning message and must be enclosed in double quotes.
- `removal_date` is used only to generate the warning message and does not control the actual removal time of the interface.

## Examples

The following code uses this macro to mark the [asc_muls](../../deprecated_interface/asc_muls_deprecated.md) interface declaration and recommends using the [asc_mul_scalar_float2half_rn](../../reg_compute/reg_fused/asc_mul_scalar_float2half_rn.md) interface instead.

```cpp
#include "c_api/defs/macro.h"

ASC_DEPRECATED(9.2.0, "2027/09/07", asc_mul_scalar_float2half_rn)
__simd_callee__ inline void asc_muls(vector_half& dst, vector_float src, float value, vector_bool mask);
```

When `asc_muls` is called, the warning message generated by the compiler is as follows:

```text
Deprecated since 9.2.0, Will be removed after 2027/09/07, Use asc_mul_scalar_float2half_rn instead.
```
