## Description

Generates the corresponding mask register based on the input parameters. The generated mask is used to constrain the computation range of a **RegTensor**. When the mask is passed as a parameter to other functions, only the elements corresponding to **True** in the mask participate in the computation.

## Prototype

  ```cpp
  asc_create_mask_b8(pat_mode)
  asc_create_mask_b16(pat_mode)
  asc_create_mask_b32(pat_mode)
  ```

## Parameters

| Parameter       | Input/Output | Description                |
| --------- | ----- | ----------------- |
| pat_mode  | Input | Creation mode of the mask register. **pat_mode** indicates the range of selected elements, defined as follows:<br><code>PAT_ALL, // All elements participate in the computation.<br>PAT_VL1, // The lowest 1 element.<br>PAT_VL2, // The lowest 2 elements.<br>PAT_VL3, // The lowest 3 elements.<br>PAT_VL4, // The lowest 4 elements.<br>PAT_VL8, // The lowest 8 elements.<br>PAT_VL16, // The lowest 16 elements.<br>PAT_VL32, // The lowest 32 elements.<br>PAT_VL64, // The lowest 64 elements.<br>PAT_VL128, // The lowest 128 elements.<br>PAT_M3, // Elements whose indexes are multiples of 3.<br>PAT_M4, // Elements whose indexes are multiples of 4.<br>PAT_H, // The lower half of the elements.<br>PAT_Q, // The lower quarter of the elements.<br>PAT_ALLF = 15 // No element participates in the computation.<br>|

## Return Value

Generates the corresponding mask register based on the mode provided above. The data type is **vector_bool**, and its bit width is fixed at VL/8. If the mask is generated by calling `asc_create_mask_b8`, one bit position in the return value corresponds to one element. If a non-b8 mask is generated, N (N = data bit width/8) bits in the return value correspond to one element, and only the low bits are valid.

PIPE_V
