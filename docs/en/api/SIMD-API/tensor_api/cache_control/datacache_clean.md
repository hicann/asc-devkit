## Function Description

The header file path is `tensor_api/tensor.h`.

Marks all cache lines of the entire Data Cache as invalid. This API does not write back dirty data, so modifications that have not been synchronized to the main memory are discarded. After the call, data is reloaded from Global Memory on the next access to the relevant addresses.

## Prototype

```cpp
__aicore__ inline void datacache_clean()
```

## Parameters

None

## Return Value

None

## Constraints

Before calling this API, call [sync_data_barrier](../sync/data_barrier.md) first and set the parameter to `mem_dsb_t::DSB_ALL` to wait for the preceding memory access instructions to complete.

## Example

In the following example, dirty data is first generated by writing to GM through Scalar, then this API is called to invalidate the entire DCache, and finally the GM data is read again.

```cpp
#include <cstdint>

#include "tensor_api/tensor.h"

constexpr int32_t dirty_value = 101;

__global__ __vector__ void cache_clean_kernel(__gm__ int32_t* data, __gm__ int32_t* output)
{
    using namespace asc::te;
    volatile __gm__ int32_t* data_gm = data;

    data_gm[0] = dirty_value;
    datacache_clean();
    output[0] = data_gm[0];
}
```
