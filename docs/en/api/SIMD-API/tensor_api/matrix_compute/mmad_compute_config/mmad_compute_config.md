# mmad Computation Configuration

<!-- md-trans-meta sourceCommit=7b36bb07889b61179ceefa6904303c10d9dd5ef4 translatedAt=2026-11-19T02:38:39.921Z pushedAt=2026-11-19T05:54:06.644Z nl=2 -->

The Tensor API provides the following matrix computation configuration APIs:

- **[enable_hf32](enable_hf32.md)**: Enables HF32 mode.
- **[disable_hf32](disable_hf32.md)**: Disables HF32 mode.
- **[set_hf32_round_mode](set_hf32_round_mode.md)**: Sets the rounding mode for HF32 mode.
- **[set_mmad_direction](set_mmad_direction.md)**: Sets the computation direction of matrix multiplication.
