# HF32

## Description

The core function of HF32 is as follows: In scenarios where both input cubes A and B are of the `fp32` data type, after the HF32 switch is enabled, the `fp32` data is converted and rounded to the HF32 (half-fp32) format before the cube multiplication is performed. This approach can double the computational performance of the [`mmad`](../mmad_compute/mmad.md) (`fp32`->`fp32`) API, but it introduces a certain degree of precision loss. Note that although the intermediate computation uses the HF32 format, the final result is still output in the `fp32` format to ensure compatibility with subsequent processing.

> **Note:** Enabling HF32 introduces precision loss. The `fp32` input data is converted and rounded to the HF32 format before the cube multiplication is performed.

Rounding mode description: The rounding mode used in the `fp32`-to-`HF32` conversion is configured through the [`asc_set_hf32_round_mode`](../../../c_api/cube_compute/asc_set_hf32_round_mode.md) API. When the `HF32` mode is enabled and the rounding mode is `asc_hf32_round_mode::NEAREST_AWAY`, `FP32` is rounded to `HF32` by rounding to the nearest value, with ties rounded away from zero. If the rounding mode is `asc_hf32_round_mode::NEAREST_EVEN`, `FP32` is rounded to `HF32` by rounding to the nearest value, with ties rounded to even.

## Constraints

- HF32 applies to `mmad` (`fp32`->`fp32`) scenarios where both input cubes A and B are of the `fp32` data type.
- Before using HF32 mode, enable HF32 mode through [asc_enable_hf32](../../../c_api/cube_compute/asc_enable_hf32.md); the rounding mode during the `fp32`-to-HF32 conversion is configured by [asc_set_hf32_round_mode](../../../c_api/cube_compute/asc_set_hf32_round_mode.md).

## Example

Use [asc_enable_hf32](../../../c_api/cube_compute/asc_enable_hf32.md) to enable HF32 mode, use [asc_disable_hf32](../../../c_api/cube_compute/asc_disable_hf32.md) to disable HF32 mode, and use [asc_set_hf32_round_mode](../../../c_api/cube_compute/asc_set_hf32_round_mode.md) to configure the rounding mode.

```cpp
#include "tensor_api/tensor.h"

using namespace asc::te;

// Enable HF32 mode.
asc_enable_hf32();
// Set the rounding mode to round to the nearest value, with ties rounded away from zero, as HF32.
asc_set_hf32_round_mode(asc_hf32_round_mode::NEAREST_AWAY);
// mmad computation code.
mmad_params params(m, n, k, unit_flag_mode::disable, true);
auto atom = make_mmad(mmad_operation{}, mmad_trait_default{}).with(params);
mmad(atom, l0c, l0a, l0b);

// Disable HF32 mode.
asc_disable_hf32();
```
