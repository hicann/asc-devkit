# Special Register Access

The Tensor API provides saturation control and squeeze status query APIs:

- **[get_saturation_flag](get_saturation_flag.md)**: Reads whether saturation is currently enabled in saturation mode.
- **[get_saturation_strategy](get_saturation_strategy.md)**: Reads the current saturation control strategy.
- **[get_squeeze_status](get_squeeze_status.md)**: Reads the valid data length after the squeeze operation.
- **[set_saturation_flag](set_saturation_flag.md)**: Sets the saturation switch in saturation mode.
- **[set_saturation_strategy](set_saturation_strategy.md)**: Sets the saturation control strategy.
