## Function Description

Header file path: `"tensor_api/experimental/arch/vector/basic_arithmetic.h"`.

This API performs element-wise subtraction on the input elements according to `src0.mask` and returns the subtraction result and the no-borrow flag. The return value `first` stores the lower 32 bits of the subtraction result, and `second` stores the no-borrow flag: 1 indicates no borrow occurred in this subtraction, and 0 indicates a borrow occurred in this subtraction.

The hardware treats the bit patterns of the source operands as 32-bit unsigned numbers and implements subtraction through two's complement addition. Both the input and output flags are interpreted according to the unsigned borrow rule and do not indicate whether a signed operation overflows. This API provides the following two forms, both of which output the no-borrow flag.

### [Subtraction Without Input Carry Flag](#sub-carry-without-carry-src)

`sub_carry(src0, src1)` directly computes `src0 - src1` without considering whether a borrow occurred in the previous step. It applies to independent subtraction or the least significant part of multi-word subtraction. The calculation formula is as follows:

$$
\{second_i, first_i\} = \{1'b0, src0_i\} + \{1'b0, \sim src1_i\} + 33'b1
$$

Here, `~src1_i` denotes the bitwise inversion of the 32-bit pattern of src1, `first` stores the lower 32 bits of the two's complement addition result, and `second` stores the carry flag of the most significant bit: 1 indicates no borrow, and 0 indicates borrow.

### [Subtraction with Input Carry Flag](#sub-carry-with-carry-src)

`sub_carry(src0, src1, carry_src)` receives the borrow state computed in the previous step through `carry_src`: 1 indicates no borrow in the previous step, so `src0 - src1` is computed; 0 indicates a borrow in the previous step, so `src0 - src1 - 1` is computed. This form is suitable for the high-order computation of multi-word subtraction, where it subtracts the 1 borrowed from the low-order computation by the high-order computation. The calculation formula is as follows:

$$
\{second_i, first_i\} = \{1'b0, src0_i\} + \{1'b0, \sim src1_i\} + \{32'b0, carry\_src_i\}
$$

Here, `first` stores the low 32 bits of the two's complement addition result, and `second` stores the carry flag generated by this computation: 1 indicates no borrow, and 0 indicates a borrow. In multi-word subtraction, the `second` returned by the low-order computation can be directly passed as the `carry_src` of the high-order computation.

## Return Value

The return type is `reg_pair<T, bool>`: `first` stores the lower 32 bits of the subtraction result, and `second` stores the no-borrow flag, where a corresponding element of 1 indicates no borrow and 0 indicates borrow. The `mask` of both members is set to `src0.mask`.

## Constraints

- src0.mask must be set in advance through the `with_mask` API. If it is not set, the content of mask is undefined, which may cause incorrect element positions to participate in the computation.

## Example

### Subtraction Without Input Carry Flag

```cpp
#include "tensor_api/experimental/vector_ops.h"

template <typename InputTensor, typename OutputTensor>
__simd_vf__ inline void sub_carry_vf(
    const InputTensor input0, const InputTensor input1, OutputTensor output, uint16_t repeat_times,
    uint32_t total, uint32_t one_repeat_size)
{
    using data_type = typename InputTensor::data_type;
    uint32_t remain = total;
    for (uint16_t i = 0; i < repeat_times; ++i) {
        const uint32_t offset = i * one_repeat_size;
        const auto coord = asc::te::make_coord(offset);
        auto mask = asc::te::experimental::update_mask<data_type>(remain);
        auto src0_reg = asc::te::experimental::load(input0, coord).with_mask(mask);
        auto src1_reg = asc::te::experimental::load(input1, coord);
        auto result = asc::te::experimental::sub_carry(src0_reg, src1_reg);
        asc::te::experimental::store(output, coord, result.first);
    }
}
```

### Subtraction with Input Carry Flag

In this example, `none_mask<data_type>()` sets the input flag to 0, so the elements involved in the computation perform `src0 - src1 - 1`. If the extra subtraction of 1 is not required, use `all_mask<data_type>()` to set the input flag to 1.

```cpp
#include "tensor_api/experimental/vector_ops.h"

template <typename InputTensor, typename OutputTensor>
__simd_vf__ inline void sub_carry_with_carry_vf(
    const InputTensor input0, const InputTensor input1, OutputTensor output, uint16_t repeat_times,
    uint32_t total, uint32_t one_repeat_size)
{
    using data_type = typename InputTensor::data_type;
    uint32_t remain = total;
    for (uint16_t i = 0; i < repeat_times; ++i) {
        const uint32_t offset = i * one_repeat_size;
        const auto coord = asc::te::make_coord(offset);
        auto mask = asc::te::experimental::update_mask<data_type>(remain);
        auto src0_reg = asc::te::experimental::load(input0, coord).with_mask(mask);
        auto src1_reg = asc::te::experimental::load(input1, coord);
        auto carry_src = asc::te::experimental::none_mask<data_type>();
        auto result = asc::te::experimental::sub_carry(src0_reg, src1_reg, carry_src);
        asc::te::experimental::store(output, coord, result.first);
    }
}
```
