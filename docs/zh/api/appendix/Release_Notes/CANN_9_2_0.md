# C API

CANN 9.2.0在CANN 9.1.0的基础上继续增强C API。本版本新增矩阵与数据搬运配置、Reg计算与搬运、缓存和特殊寄存器控制等能力，为大量Reg接口补充函数返回值形式的重载，并统一公共头文件、接口命名和参数类型。同时，部分旧命名、隐式位置重载和同步复合接口进入废弃期。

## 新增特性

### 系统、缓存与控制

- [asc_disable_dma_atomic](../../SIMD-API/c_api/atomic/datamove_atomic/asc_disable_dma_atomic.md)：在完成数据搬运原子操作后关闭原子操作，避免已开启的原子操作影响后续搬运。该接口支持Atlas A2系列产品和Atlas A3系列产品，以及Ascend 950PR&950DT系列产品。
- [asc_set_atomic_add_int32](../../SIMD-API/c_api/atomic/datamove_atomic/asc_set_atomic_add.md)、[asc_set_atomic_max_int32](../../SIMD-API/c_api/atomic/datamove_atomic/asc_set_atomic_max.md)和[asc_set_atomic_min_int32](../../SIMD-API/c_api/atomic/datamove_atomic/asc_set_atomic_min.md)：分别开启数据搬运过程中的`int32_t`原子加、原子最大值和原子最小值操作，使用明确的数据类型后缀替代旧的`*_int`命名。该组接口支持Atlas A2系列产品和Atlas A3系列产品，以及Ascend 950PR&950DT系列产品。
- [asc_get_pipe_mte2_idle_slot_count](../../SIMD-API/c_api/experimental/asc_get_pipe_idle_slot_count.md)、[asc_get_pipe_mte3_idle_slot_count](../../SIMD-API/c_api/experimental/asc_get_pipe_idle_slot_count.md)、[asc_get_pipe_v_idle_slot_count](../../SIMD-API/c_api/experimental/asc_get_pipe_idle_slot_count.md)、[asc_get_pipe_m_idle_slot_count](../../SIMD-API/c_api/experimental/asc_get_pipe_idle_slot_count.md)、[asc_get_pipe_mte1_idle_slot_count](../../SIMD-API/c_api/experimental/asc_get_pipe_idle_slot_count.md)和[asc_get_pipe_fix_idle_slot_count](../../SIMD-API/c_api/experimental/asc_get_pipe_idle_slot_count.md)：分别查询PIPE_MTE2、PIPE_MTE3、PIPE_V、PIPE_M、PIPE_MTE1和PIPE_FIX发射队列当前的空闲槽位数量，用于观察队列还能接收的待发射指令数量。该组接口仅支持Ascend 950PR&950DT系列产品，属于试验特性，使用时需包含`c_api/experimental/asc_get_pipe_idle_slot_count.h`并定义`CANN_ASC_USE_EXPERIMENTAL`。
- [asc_set_scalar_cache_mode](../../SIMD-API/c_api/cache_ctrl/asc_set_scalar_cache_mode.md)、[asc_get_scalar_load_cache_mode](../../SIMD-API/c_api/cache_ctrl/asc_get_scalar_load_cache_mode.md)、[asc_get_scalar_store_cache_mode](../../SIMD-API/c_api/cache_ctrl/asc_get_scalar_store_cache_mode.md)：支持分别设置标量读、写Global Memory时的L2 Cache管理策略，以及回读当前的标量读、写策略。设置后的策略持续生效，直至再次调用设置接口修改。该组接口仅支持Ascend 950PR&950DT系列产品。
- [asc_set_saturation_flag](../../SIMD-API/c_api/spr/asc_set_saturation_flag.md)和[asc_get_saturation_flag](../../SIMD-API/c_api/spr/asc_get_saturation_flag.md)：支持通过[asc_saturation_mode](../../SIMD-API/c_api/defs/enum/asc_saturation_mode.md)设置或查询浮点、FP8、整数和类型转换场景的饱和开关；[asc_set_saturation_strategy](../../SIMD-API/c_api/spr/asc_set_saturation_strategy.md)和[asc_get_saturation_strategy](../../SIMD-API/c_api/spr/asc_get_saturation_strategy.md)支持通过[asc_override_strategy](../../SIMD-API/c_api/defs/enum/asc_override_strategy.md)在单指令/API路径配置与全局饱和配置之间切换和查询。其中，类型转换场景的全局饱和开关仅在使用全局饱和配置时生效。该组接口仅支持Ascend 950PR&950DT系列产品。
- [asc_get_system_clock](../../SIMD-API/c_api/utils/sys_var/asc_get_system_clock.md)：读取当前系统cycle计数器，按芯片时钟频率换算后直接返回`int64_t`类型的微秒级时间值，在AIC和AIV上的返回值含义一致。CANN 9.1.0中已有的[asc_get_system_cycle](../../SIMD-API/c_api/utils/sys_var/asc_get_system_cycle.md)仍用于读取原始cycle计数值。该接口支持Atlas A2系列产品和Atlas A3系列产品，以及Ascend 950PR&950DT系列产品。
- [asc_nop](../../SIMD-API/c_api/utils/sys_misc/asc_nop.md)：生成一条空操作指令，不执行实际计算。每调用一次阻塞一拍流水。该接口仅支持Ascend 950PR&950DT系列产品。

### 矩阵计算与数据搬运

- [asc_disable_hf32](../../SIMD-API/c_api/cube_compute/asc_disable_hf32.md)：关闭Mmad计算的HF32模式，使L0A Buffer和L0B Buffer中的`float`数据在参与计算前不做舍入处理；[asc_disable_hif8](../../SIMD-API/c_api/cube_compute/asc_disable_hif8.md)：关闭HiF8模式，使左右矩阵均为`fp8_e4m3fn_t`时不再转换为`hifloat8_t`，而是直接参与矩阵乘法。两个接口均为仅在AIC上生效的矩阵计算配置接口。其中，`asc_disable_hf32`支持Atlas A2系列产品和Atlas A3系列产品，以及Ascend 950PR&950DT系列产品，`asc_disable_hif8`仅支持Ascend 950PR&950DT系列产品。
- [asc_set_hf32_round_mode](../../SIMD-API/c_api/cube_compute/asc_set_hf32_round_mode.md)：使用[asc_hf32_round_mode](../../SIMD-API/c_api/defs/enum/asc_hf32_round_mode.md)枚举配置HF32舍入方式，调用前需先开启HF32模式。该接口支持Atlas A2系列产品和Atlas A3系列产品，以及Ascend 950PR&950DT系列产品。
- [asc_set_gm2l1_padding](../../SIMD-API/c_api/cube_datamove/asc_set_gm2l1_padding.md)：配置GM到L1 Buffer高维切分搬运的Padding值；[asc_set_l12l0a_3d_padding](../../SIMD-API/c_api/cube_datamove/asc_set_l12l0a_3d_padding.md)和[asc_set_l12l0b_3d_padding](../../SIMD-API/c_api/cube_datamove/asc_set_l12l0b_3d_padding.md)：分别配置左、右矩阵3D im2col搬运的填充值；[asc_set_l13d_rpt_b](../../SIMD-API/c_api/cube_datamove/asc_set_l13d_rpt_b.md)：配置3D im2col模式下右矩阵使用repeat搬运所需的参数。该组接口均仅在AIC上生效；其中，`asc_set_gm2l1_padding`和`asc_set_l12l0a_3d_padding`同时支持Atlas A2系列产品和Atlas A3系列产品，以及Ascend 950PR&950DT系列产品，其余接口仅支持Ascend 950PR&950DT系列产品。
- [asc_set_l0c_copy_config](../../SIMD-API/c_api/cube_datamove/asc_set_l0c_copy_config.md)：配置L0C Buffer搬出时随路Tensor量化、Tensor激活参数在Fixpipe Buffer中的起始索引，并支持初始化UnitFlag全局状态；[asc_set_l0c_copy_channel_para](../../SIMD-API/c_api/cube_datamove/asc_set_l0c_copy_channel_para.md)：配置Nz2DN格式转换时源Nz矩阵相邻行的地址偏移；[asc_set_l0c_copy_nz_para](../../SIMD-API/c_api/cube_datamove/asc_set_l0c_copy_nz_para.md)：配置随路Nz转ND/DN所需参数；[asc_set_l0c_copy_relu_alpha](../../SIMD-API/c_api/cube_datamove/asc_set_l0c_copy_relu_alpha.md)和[asc_set_l0c_copy_lrelu_alpha](../../SIMD-API/c_api/cube_datamove/asc_set_l0c_copy_lrelu_alpha.md)：配置随路Scalar激活的缩放系数。该组配置由后续L0C Buffer搬出接口使用，且仅在AIC上生效。其中，`asc_set_l0c_copy_config`和`asc_set_l0c_copy_lrelu_alpha`同时支持Atlas A2系列产品和Atlas A3系列产品，以及Ascend 950PR&950DT系列产品，其余接口仅支持Ascend 950PR&950DT系列产品。新接口`asc_set_l0c_copy_lrelu_alpha`仅提供`float`参数形式；CANN 9.1.0已有的[asc_set_l0c2gm_lrelu_alpha](../../SIMD-API/c_api/deprecated_interface/asc_set_l0c2gm_lrelu_alpha_deprecated.md)仍提供`half&`和`float&`参数形式。

### 标量计算

- [asc_load_dev](../../SIMD-API/c_api/scalar_compute/scalar_load/asc_load_dev.md)：不经过Data Cache直接从Global Memory读取整型标量数据，适用于多核访问无法按Cache Line对齐的GM地址、需要避免Cache Line粒度数据覆盖的场景。该接口仅支持Ascend 950PR&950DT系列产品。
- [asc_float2half_ro](../../SIMD-API/c_api/scalar_compute/scalar_convert/asc_float2half.md)：在标量流水上将`float`转换为`half`并直接返回结果，舍入模式固定为ODD（最近邻奇数舍入）。该接口仅支持Ascend 950PR&950DT系列产品。

### Memory矢量计算

- [asc_transto5hd](../../SIMD-API/c_api/vector_compute/vector_permute_sel/asc_transto5hd.md)：将[asc_transto5hd_b8](../../SIMD-API/c_api/vector_compute/vector_permute_sel/asc_transto5hd.md)、[asc_transto5hd_b16](../../SIMD-API/c_api/vector_compute/vector_permute_sel/asc_transto5hd.md)和[asc_transto5hd_b32](../../SIMD-API/c_api/vector_compute/vector_permute_sel/asc_transto5hd.md)正式加入公共头文件，用于NCHW到NC1HWC0格式转换或二维矩阵数据块转置。单次Repeat处理512 Byte（16个DataBlock），并支持多次Repeat操作。该组接口支持Atlas A2系列产品和Atlas A3系列产品，以及Ascend 950PR&950DT系列产品。
- [asc_set_vector_mask](../../SIMD-API/c_api/vector_compute/vector_mask_config/asc_set_vector_mask.md)新增Ascend 950PR&950DT系列产品支持，可在Vector Function外配置掩码寄存器，并配合Reg矢量计算接口使用。

### Reg计算与Reg数据搬运

本节新增接口均仅支持Ascend 950PR&950DT系列产品，并在AIV的Vector Function中调用。

- [asc_duplicate_highest](../../SIMD-API/c_api/reg_compute/reg_broadcast/asc_duplicate_highest.md)和[asc_duplicate_highest_merge](../../SIMD-API/c_api/reg_compute/reg_broadcast/asc_duplicate_highest_merge.md)：将源操作数中下标最大的元素广播到被掩码选中的目的位置，未选中位置分别置0或保留原值；[asc_duplicate_merge](../../SIMD-API/c_api/reg_compute/reg_broadcast/asc_duplicate_merge.md)和[asc_duplicate_scalar_merge](../../SIMD-API/c_api/reg_compute/reg_broadcast/asc_duplicate_scalar_merge.md)：分别将源操作数中下标最小的元素或给定标量广播到被掩码选中的目的位置，并保留未选中位置的原值。
- [asc_mask](../../SIMD-API/c_api/reg_compute/reg_copy/asc_mask.md)：支持通过函数返回值完成矢量数据寄存器或掩码寄存器的掩码复制；[asc_extract_mask](../../SIMD-API/c_api/reg_compute/reg_copy/asc_extract_mask.md)：从`uint16_t`或`uint32_t`矢量数据寄存器的指定数据块中提取并扩展bit，生成掩码寄存器返回值。
- [asc_pack_to_low](../../SIMD-API/c_api/reg_compute/reg_permute_sel/asc_pack_to_low.md)和[asc_pack_to_high](../../SIMD-API/c_api/reg_compute/reg_permute_sel/asc_pack_to_high.md)：选取源操作数的偶数bit（`vector_bool`）、低8位（b16）或低16位（b32），并分别写入目的操作数的低半部分或高半部分。
- [asc_unsqueeze](../../SIMD-API/c_api/reg_compute/reg_permute_sel/asc_unsqueeze.md)新增[asc_unsqueeze_s8](../../SIMD-API/c_api/reg_compute/reg_permute_sel/asc_unsqueeze.md)、[asc_unsqueeze_u8](../../SIMD-API/c_api/reg_compute/reg_permute_sel/asc_unsqueeze.md)、[asc_unsqueeze_s16](../../SIMD-API/c_api/reg_compute/reg_permute_sel/asc_unsqueeze.md)、[asc_unsqueeze_u16](../../SIMD-API/c_api/reg_compute/reg_permute_sel/asc_unsqueeze.md)、[asc_unsqueeze_s32](../../SIMD-API/c_api/reg_compute/reg_permute_sel/asc_unsqueeze.md)和[asc_unsqueeze_u32](../../SIMD-API/c_api/reg_compute/reg_permute_sel/asc_unsqueeze.md)，支持通过函数返回值获取掩码前缀计数结果：首元素为0，第`i`个元素为掩码第0至第`i-1`个元素中1的数量，掩码最高位不参与统计。
- [asc_fma](../../SIMD-API/c_api/reg_compute/reg_fused/asc_fma.md)、[asc_mula](../../SIMD-API/c_api/reg_compute/reg_fused/asc_mula.md)和[asc_mul_scalar_float2half_rn](../../SIMD-API/c_api/reg_compute/reg_fused/asc_mul_scalar_float2half_rn.md)：分别支持三源融合乘加、目的操作数作为累加器参与乘加，以及`float`矢量与标量相乘后按RINT模式转换为`half`并写入指定奇偶位置。其中，`asc_fma`在CANN 9.1.0中仅有Memory矢量计算接口，本版本新增的是Reg接口。
- [asc_exp_sub](../../SIMD-API/c_api/reg_compute/reg_fused/asc_exp_sub.md)新增[asc_exp_sub_half2float](../../SIMD-API/c_api/reg_compute/reg_fused/asc_exp_sub.md)接口，支持显式选择`half`源操作数的奇数或偶数索引元素，转换为`float`后逐元素计算以两源差值为指数的自然指数函数；[asc_log](../../SIMD-API/c_api/reg_compute/reg_arith/asc_log.md)新增Reg逐元素自然对数计算接口。
- [asc_squeeze_and_storeunalign_init](../../SIMD-API/c_api/reg_compute/reg_permute_sel/asc_squeeze_and_storeunalign_init.md)清零AR特殊寄存器；[asc_squeeze_and_storeunalign](../../SIMD-API/c_api/reg_compute/reg_permute_sel/asc_squeeze_and_storeunalign.md)按掩码筛选矢量寄存器元素，将结果连续搬出到非32字节对齐的UB地址，并在AR寄存器中累计有效数据总字节数；[asc_squeeze_and_storeunalign_finalize](../../SIMD-API/c_api/reg_compute/reg_permute_sel/asc_squeeze_and_storeunalign_finalize.md)将不足32 Byte、暂存在非对齐寄存器中的尾块写入UB。
- [asc_get_squeeze_status](../../SIMD-API/c_api/spr/asc_get_squeeze_status.md)：读取squeeze操作保存在AR特殊寄存器中的有效数据长度；[asc_storealign_squeeze_status](../../SIMD-API/c_api/reg_compute/store/asc_storealign_squeeze_status.md)和[asc_storealign_squeeze_status_postupdate](../../SIMD-API/c_api/reg_compute/store/asc_storealign_squeeze_status_postupdate.md)：将该长度搬出到UB，后者还会在写入后按字节偏移自动更新目的地址。
- Reg对齐搬入新增语义明确的模式接口：[asc_loadalign_brc_datablock](../../SIMD-API/c_api/reg_compute/load/asc_loadalign_brc_datablock.md)广播一个32 Byte DataBlock，[asc_loadalign_brc_elem](../../SIMD-API/c_api/reg_compute/load/asc_loadalign_brc_elem.md)广播一个元素，[asc_loadalign_brc_elem2datablock](../../SIMD-API/c_api/reg_compute/load/asc_loadalign_brc_elem2datablock.md)连续读取8个元素并将每个元素广播为一个DataBlock，[asc_loadalign_unpack4](../../SIMD-API/c_api/reg_compute/load/asc_loadalign_unpack4.md)读取VL/4长度数据并在每个元素后补3个0；对应的[asc_loadalign_brc_datablock_postupdate](../../SIMD-API/c_api/reg_compute/load/asc_loadalign_brc_datablock_postupdate.md)、[asc_loadalign_brc_elem_postupdate](../../SIMD-API/c_api/reg_compute/load/asc_loadalign_brc_elem_postupdate.md)、[asc_loadalign_brc_elem2datablock_postupdate](../../SIMD-API/c_api/reg_compute/load/asc_loadalign_brc_elem2datablock_postupdate.md)和[asc_loadalign_unpack4_postupdate](../../SIMD-API/c_api/reg_compute/load/asc_loadalign_unpack4_postupdate.md)在搬入后自动更新源地址。新增[asc_loadalign_datablock_strided](../../SIMD-API/c_api/reg_compute/load/asc_loadalign_datablock_strided.md)、[asc_loadalign_mask](../../SIMD-API/c_api/reg_compute/load/asc_loadalign_mask.md)、[asc_loadalign_mask_downsample](../../SIMD-API/c_api/reg_compute/load/asc_loadalign_mask_downsample.md)和[asc_loadalign_mask_upsample](../../SIMD-API/c_api/reg_compute/load/asc_loadalign_mask_upsample.md)返回值接口，分别支持跨步搬入8个DataBlock，以及直接返回原始、偶数bit下采样和bit二倍重复上采样的掩码寄存器。
- [asc_storealign_pack_quarter](../../SIMD-API/c_api/reg_compute/store/asc_storealign_pack_quarter.md)和[asc_storealign_pack_quarter_postupdate](../../SIMD-API/c_api/reg_compute/store/asc_storealign_pack_quarter_postupdate.md)：按掩码将32位Reg有效元素的低8位压缩搬出到UB，后者在搬出后按偏移自动更新目的地址。
- [asc_update_addr_reg](../../SIMD-API/c_api/reg_compute/reg_addr_reg/asc_update_addr_reg.md)接口族新增[asc_update_addr_reg_b8](../../SIMD-API/c_api/reg_compute/reg_addr_reg/asc_update_addr_reg.md)、[asc_update_addr_reg_b16](../../SIMD-API/c_api/reg_compute/reg_addr_reg/asc_update_addr_reg.md)和[asc_update_addr_reg_b32](../../SIMD-API/c_api/reg_compute/reg_addr_reg/asc_update_addr_reg.md)，分别按1 Byte、2 Byte和4 Byte为单位计算1至4维循环的地址偏移，使用[addr_reg](../../SIMD-API/c_api/defs/type/data_type_definition.md#地址寄存器)保存偏移并配合Reg搬入、搬出接口完成迭代寻址，替代原[iter_reg](../../SIMD-API/c_api/deprecated_interface/asc_create_iter_reg_deprecated.md)接口族。

## 增强

### Reg计算
