# 通用约束说明

本文介绍SIMT数学函数与类型转换接口的通用约束。当前内容包括饱和模式设置：饱和行为对nan、inf特殊值以及转换后超出目标类型范围结果的处理方式，以及CTRL寄存器与接口后缀对饱和行为的控制方式。饱和与溢出的系统性介绍请参见《浮点计算基础》的[饱和与溢出处理](../../../guide/technical_appendix/floating_point_computation/floating_point_basics.md#饱和与溢出处理)章节。

## 饱和模式设置

### 饱和行为

**表1** 饱和行为的模式说明

| 模式 | 描述 | 接口名格式 |
| --- | --- | --- |
| 非饱和模式 | 默认模式。<br>如果输入超出该类型所能表示的范围，转换结果为对应符号的inf值。<br>如果输入为nan，转换结果为nan。 | srctype2dsttype_r[xx] |
| 饱和模式 | 饱和模式下：<br>如果输入为+inf，或者超出该类型所能表示的最大值，转换结果为最大值。<br>如果输入为-inf，或者小于该类型所能表示的最小值，转换结果为最小值。<br>如果输入为nan，转换结果为0。 | srctype2dsttype_r[xx]_sat |

### 控制饱和行为的方式

饱和行为受寄存器CTRL\[60\]、CTRL\[48\]和接口功能同时控制，SIMD与SIMT混合编程场景下，CTRL寄存器的设置请参考[SetCtrlSpr\(ISASI\)](../../SIMD-API/basic_api/special_register_access/SetCtrlSpr_ISASI.md)接口。**SIMT编程场景暂不支持设置CTRL寄存器。**

宽范围数据转成窄范围数据且转换的目标类型不是float时，包括float转half、float转bfloat16\_t、bfloat16\_t转half、float或half转hifloat8\_t、fp8\_e4m3fn\_t或fp8\_e5m2\_t，接口的饱和行为受硬件寄存器CTRL\[60\]和CTRL\[48\]的影响。具体行为如下：

-   当CTRL\[60\] = 0时，饱和行为受接口独立控制。
    -   后缀\_\_sat的接口转换结果为饱和模式。
    -   不带\_\_sat后缀的接口转换结果为非饱和模式。

-   当CTRL\[60\] = 1时，饱和行为只受CTRL\[48\]全局控制。
    -   当CTRL\[48\] = 1时，接口转换结果为非饱和模式。
    -   当CTRL\[48\] = 0时，接口转换结果为饱和模式。

**表2** 宽范围数据转窄范围数据的最终饱和行为

| Ctrl[60] | Ctrl[48] | 接口名格式 | 最终饱和行为 |
| --- | --- | --- | --- |
| 0 | / | 不带__sat | 非饱和 |
| 1 | 1 | / | 非饱和 |
| 0 | / | __sat | 饱和 |
| 1 | 0 | / | 饱和 |

对如下两种情况，饱和行为只受CTRL\[48\]控制。

-   窄范围数据转换为宽范围数据，且转换的目的操作数类型不是float，即half转bfloat16\_t、hifloat8\_t转half。
-   half转half、bfloat16\_t转bfloat16\_t。

具体行为如下：

-   当CTRL\[48\] = 1时，接口转换结果为非饱和模式。
-   当CTRL\[48\] = 0时，接口转换结果为饱和模式。

**表3** 窄范围数据转宽范围数据、同类型数据转换最终饱和行为

| Ctrl[60] | Ctrl[48] | 最终饱和行为 |
| --- | --- | --- |
| / | 1 | 非饱和 |
| / | 0 | 饱和 |

对于转换的目标类型为float的情况，所有类型转换接口只支持非饱和模式。浮点数转换为整数时，转换结果均采用饱和模式。
