## 功能说明

头文件路径为：`"simt_api/asc_bf16.h"`。

将bfloat16\_t数据遵循CAST\_ROUND模式取整。

## 函数原型

```cpp
inline bfloat16_t __bfloat162bfloat16_rna(const bfloat16_t x)
```

## 参数说明

**表1**  参数说明

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| x | 输入 | 源操作数。 |

## 返回值说明

输入遵循CAST\_ROUND模式取整后的bfloat16\_t类型数据。本接口受全局饱和模式影响，特殊值如下：

| x值 | 非饱和模式返回值 | 饱和模式返回值 |
|---|---|---|
| ±0 | 0 | 0 |
| nan | nan | 0 |
| inf | inf | ASCRT_MAX_NORMAL_BF16 |
| -inf | -inf | -ASCRT_MAX_NORMAL_BF16 |
| ASCRT_MIN_DENORM_BF16 | 0 | 0 |
| 0.5 | 1.0 | 1.0 |
| 1.5 | 2.0 | 2.0 |
| 2.5 | 3.0 | 3.0 |
| -1.5 | -2.0 | -2.0 |

## 约束说明

无
