# HF32

## 特性说明

HF32的核心功能体现为：用户在输入矩阵A和B都为`fp32`数据类型的场景下，当配置开启HF32开关后，`fp32`数据在执行矩阵乘法运算前会被转换并舍入为HF32（half-fp32）格式。这种做法可使[`mmad`](../mmad_compute/mmad.md)（`fp32`->`fp32`）接口的计算性能提升至原来的两倍，但会带来一定的精度损失。需要注意的是，尽管中间计算使用HF32格式，最终的运算结果仍以`fp32`格式输出，以保证后续处理的兼容性。

> **注意：** 启用HF32会引入精度损失，`fp32`输入数据会在矩阵乘法运算前转换并舍入为HF32格式。

舍入模式说明：`fp32`至`HF32`转换过程中的舍入模式由[`asc_set_hf32_round_mode`](../../../c_api/cube_compute/asc_set_hf32_round_mode.md)接口配置。当`HF32`模式开启且舍入模式为`asc_hf32_round_mode::NEAREST_AWAY`时，则`FP32`将以向最接近的值舍入，平局时远离零的方式舍入为`HF32`；若舍入模式为`asc_hf32_round_mode::NEAREST_EVEN`时，则`FP32`将以向最接近的值舍入，平局时向偶数舍入的方式舍入为`HF32`。

## 约束说明

- HF32适用于输入矩阵A和B均为`fp32`数据类型的`mmad`（`fp32`->`fp32`）场景。
- 使用HF32模式前，需要通过[asc_enable_hf32](../../../c_api/cube_compute/asc_enable_hf32.md)开启HF32模式；`fp32`至HF32转换过程中的舍入模式由[asc_set_hf32_round_mode](../../../c_api/cube_compute/asc_set_hf32_round_mode.md)配置。

## 使用示例

使用[asc_enable_hf32](../../../c_api/cube_compute/asc_enable_hf32.md)开启HF32模式，使用[asc_set_fp32_mode](../../../c_api/cube_compute/asc_set_fp32_mode.md)关闭HF32模式，使用[asc_set_hf32_round_mode](../../../c_api/cube_compute/asc_set_hf32_round_mode.md)配置舍入模式。

```cpp
#include "tensor_api/tensor.h"

using namespace asc::te;

// 开启HF32模式
asc_enable_hf32();
// 设置舍入模式为向最接近的值舍入，平局时远离零的方式舍入为HF32
asc_set_hf32_round_mode(asc_hf32_round_mode::NEAREST_AWAY);
// mmad计算代码
mmad_params params(m, n, k, unit_flag_mode::disable, true);
auto atom = make_mmad(mmad_operation{}, mmad_trait_default{}).with(params);
mmad(atom, l0c, l0a, l0b);

// 关闭HF32模式
asc_set_fp32_mode();
```
