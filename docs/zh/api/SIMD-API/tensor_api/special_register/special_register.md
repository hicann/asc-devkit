# 特殊寄存器访问

Tensor API提供饱和控制和squeeze状态查询接口：

- **[get_saturation_flag](get_saturation_flag.md)**：按饱和模式读取当前是否开启饱和。
- **[get_saturation_strategy](get_saturation_strategy.md)**：读取当前饱和控制策略。
- **[get_squeeze_status](get_squeeze_status.md)**：读取squeeze操作后的有效数据长度。
- **[set_saturation_flag](set_saturation_flag.md)**：按饱和模式设置饱和开关。
- **[set_saturation_strategy](set_saturation_strategy.md)**：设置饱和控制策略。
