# HF32

**特性说明：**

HF32的核心功能体现为：用户在输入矩阵A、B矩阵都为fp32数据类型的场景下，当配置开启HF32开关后，fp32数据在执行矩阵乘法运算前会被转换并舍入为HF32（half-fp32）格式。这种做法可使Mmad类（f322f32）接口的计算性能得到提升，但会带来一定的精度损失。需要注意的是，尽管中间计算使用HF32格式，最终的运算结果仍以fp32格式输出，以保证后续处理的兼容性。

开启HF32对性能的影响如下：

<!-- npu="A3,910b" id3 -->
- 针对如下产品型号：

  <!-- npu="A3" id4 -->
  Atlas A3 训练系列产品/Atlas A3 推理系列产品
  <!-- end id4 -->
  <!-- npu="910b" id5 -->
  Atlas A2 训练系列产品/Atlas A2 推理系列产品
  <!-- end id5 -->
  开启HF32可使Mmad类（f322f32）接口的计算性能提升至原来的两倍。
<!-- end id3 -->

<!-- npu="950" id2 -->
- 针对Ascend 950PR/Ascend 950DT产品，开启HF32可使Mmad（f322f32）接口的计算性能提升至原来的八倍。
<!-- end id2 -->

舍入模式说明：fp32至HF32转换过程中的舍入模式由[asc_set_hf32_round_mode](../asc_set_hf32_round_mode.md)接口配置。当HF32模式开启且设置asc_hf32_round_mode为NEAREST_AWAY时，FP32将以向最接近的值舍入，平局时远离零的方式舍入为HF32；若设置asc_hf32_round_mode为NEAREST_EVEN时，FP32将以向最接近的值舍入，平局时向偶数舍入的方式舍入为HF32。

**使用示例：**

```cpp
// 开启HF32模式
asc_enable_hf32();
asc_set_hf32_round_mode(asc_hf32_round_mode::NEAREST_AWAY);
asc_mmad(c, a, b, m, k, n, asc_unit_flag_mode::DISABLE,
         false, false, true);
// 关闭HF32模式并恢复舍入模式默认值
asc_disable_hf32();
asc_set_hf32_round_mode(asc_hf32_round_mode::NEAREST_EVEN);
```
