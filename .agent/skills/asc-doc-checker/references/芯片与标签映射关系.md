# 芯片标签参考

以 `docs/zh/asc_api_writing_guidelines.md` 的 `API-PROD-*` 和 `API-CUSTOM-*` 条款为准。
以下名称来自当前 API 内容页的产品支持章节，用于校验 `npu` 属性和标签内产品名称是否对应。

| `npu` 值 | 产品名称 |
|---|---|
| `950` | Ascend 950PR/Ascend 950DT |
| `A3` | Atlas A3 训练系列产品/Atlas A3 推理系列产品 |
| `910b` | Atlas A2 训练系列产品/Atlas A2 推理系列产品 |
| `310b` | Atlas 200I/500 A2 推理产品 |
| `310p` | Atlas 推理系列产品AI Core；Atlas 推理系列产品Vector Core |
| `910` | Atlas 训练系列产品 |
| `x90` | Kirin X90 |
| `9030` | Kirin 9030 |

API 内容页标签使用 HTML 注释：

```text
<!-- npu="950" id1 -->
- Ascend 950PR/Ascend 950DT：支持
<!-- end id1 -->
```

- `npu` 可包含逗号分隔的多个值，例如 `npu="950,A3,910b"`。
- 开始和结束标签必须成对；同一 Markdown 文件中的 `idN` 必须唯一。
- `idN` 不要求从 `id1` 开始或连续递增。
- 标签可包裹段落、列表、代码块和表格单元格。
- `docs/zh/api/README.md` 等索引文件可使用 `<cann-filter npu-type="...">`，不要将其规则套用到 API 内容页。
