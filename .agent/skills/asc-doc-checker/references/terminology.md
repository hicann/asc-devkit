# 术语参考

术语的唯一权威来源为
`docs/zh/guide/technical_appendix/concepts_and_terms/glossary.md`。检查任何 API 文档前，按需读取该
文件中与目标主题相关的术语；不要维护会漂移的重复术语表。

常见的检查重点：

- 物理缓冲区名称使用 `L1 Buffer`、`L0A Buffer`、`L0B Buffer`、`L0C Buffer` 等完整写法。
- `AI Core`、`Cube Core`、`Vector Core`、`Global Memory`、`Unified Buffer` 等术语的大小写和空格与
  术语表保持一致。
- 数据通路使用代码语法时保留 `->`，不要将其替换为中文箭头。

遇到术语表未覆盖或上下文不能确定的写法，报告为“需确认”，不要擅自判定为错误。
