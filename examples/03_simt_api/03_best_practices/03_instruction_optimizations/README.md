# Instruction Optimizations样例介绍

## 概述

指令优化相关样例，通过<<<>>>直调的实现方式，介绍SIMT编程方式下的指令调优思路。当前提供了原子操作优化与原地加法指令优化两类案例，展示通过分层归约、控制指令开销等方式提升指令执行效率的优化方法。

## 样例列表

| 目录名称                                               | 功能描述                                                                                        |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| [atomic_histogram](./atomic_histogram)   | 样例以直方图统计为例，对比GM全局原子累加与UB块内原子累加再合并两种实现，展示原子操作指令的调优方法与性能收益。 |
| [inplace_add_atomic](./inplace_add_atomic)   | 样例以原地加法（三操作数乘加与两操作数加法）为例，对比核内读改写与原子加两种实现，展示用原子操作将累加卸载到存储侧、减少一次主存读取的调优方法与性能收益。 |
