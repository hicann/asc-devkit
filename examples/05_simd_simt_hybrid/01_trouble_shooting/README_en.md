# SIMD and SIMT Hybrid Programming Troubleshooting Samples

## Overview

This directory provides troubleshooting samples for Ascend C SIMD and SIMT hybrid programming, including resource configuration, memory boundary checks, and issue analysis methods.

## Sample List

| Directory Name | Description | Supported Products |
| ------------------------------------------------------------ | ---------------------------------------------------- | --- |
| [simd_simt_ub_usage_limit](./simd_simt_ub_usage_limit) | Demonstrates UB static memory, dynamic memory, reserved space, Data Cache layout, and out-of-bounds troubleshooting in SIMD and SIMT hybrid programming. | Ascend 950PR/Ascend 950DT |
