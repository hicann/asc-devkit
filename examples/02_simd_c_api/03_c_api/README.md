# C_API样例介绍

## 概述

本样例介绍了Ascend C C_API的使用方法，包括数据搬运、矩阵计算类API等。

## 样例列表

| 目录名称  | 功能描述 |
| --------- | --------- |
| [00_data_movement](./00_data_movement) | 本样例路径包含了与数据搬运相关的多个C API的样例，展示了数据搬运接口的使用。|
| [02_reg_vector_compute](./02_reg_vector_compute) | 本路径下包含了与矢量数据计算相关的多个API的样例，基于Reg编程接口实现。|
| [03_matrix_compute](./03_matrix_compute) | 本样例路径以Mmad等算子为示例，展示了矩阵计算接口的使用。|
