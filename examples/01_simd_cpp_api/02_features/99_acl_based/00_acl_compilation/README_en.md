# Compilation Sample Introduction

## Overview

This sample introduces custom operator compilation projects, static library linking with aclnn execution, and multi-vendor parallel packaging samples based on Ascend C.

## Sample List

| Directory Name | Description | Supported Products |
| -------------- | ----------- | --- |
| [custom_op](./custom_op) | This sample introduces the workflow of custom operator compilation, packaging, and deployment | Ascend 950PR&950DT products<br>Atlas A3 products<br>Atlas A2 products<br>Atlas 200I/500 A2 Inference Products<br>Atlas Inference Series Products |
| [custom_op_simplified_key](./custom_op_simplified_key) | This sample introduces the compilation method for custom simplified key and BINARY_JSON Kernel Binary selection | Ascend 950PR&950DT products<br>Atlas A3 products<br>Atlas A2 products |
| [custom_op_static_lib](./custom_op_static_lib) | This sample introduces the compilation and invocation method for custom operator static libraries | Ascend 950PR&950DT products<br>Atlas A3 products<br>Atlas A2 products |
| [parallel_ops_package](./parallel_ops_package) | This sample introduces the implementation of parallel compilation, packaging, and deployment for multiple vendors | Ascend 950PR&950DT products<br>Atlas A3 products<br>Atlas A2 products<br>Atlas 200I/500 A2 Inference Products<br>Atlas Inference Series Products |
