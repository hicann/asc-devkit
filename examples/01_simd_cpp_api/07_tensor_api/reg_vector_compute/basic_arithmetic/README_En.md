# Basic Compute Sample Implemented with Tensor API

## Overview

This sample demonstrates the register basic compute API `asc::te::experimental::abs` with Tensor API. It covers `int8_t`, `int16_t`, `half`, `int32_t`, and `float`. Each typed input contains 64 elements, and the output stores the absolute value of each input element.

## Supported Products

- Ascend 950PR/Ascend 950DT

## Sample Description

- Sample function:
  The sample computes the absolute value of each input Tensor element:

  ```text
  output_i = abs(input_i)
  ```

- Sample implementation:

  - Kernel implementation

    1. Create Tensor objects on GM and UB by using `asc::te::make_tensor`, `asc::te::make_mem_ptr`, and `asc::te::make_frame_layout`.
    2. Move input data from GM to UB by using `asc::te::make_copy` and `asc::te::copy`.
    3. Load UB Tensor data as `reg_tensor` by using Tensor `load`, and use `make_mask<mask_pattern::vl64, T>()` to select 64 elements.
    4. Call `asc::te::experimental::abs` and store the result back to UB by using Tensor `store`.
    5. Move the result from UB back to GM by using `asc::te::copy`.

  - Invocation implementation

    The host program reads input files generated by `scripts/gen_data.py`, invokes the kernel function with `<<<>>>`, saves output files after execution, and verifies them with `scripts/verify_result.py`.

## Core Interface

### asc::te::experimental::abs

```cpp
template <typename T>
__simd_callee__ inline decltype(auto) abs(const reg_tensor<T>& src_reg);
```

This API computes the absolute value of an input `reg_tensor` and returns a `reg_tensor` with the same element type.

## Build and Run

Run the following steps in the sample root directory to build and execute the sample.

- Configure environment variables.

  Configure environment variables based on the CANN development toolkit installation path.

  ```bash
  source ${install_path}/cann/set_env.sh
  ```

- Run the sample.

  ```bash
  mkdir -p build && cd build
  cmake -DCMAKE_ASC_ARCHITECTURES=dav-3510 ..
  make -j
  python3 ../scripts/gen_data.py
  ./demo
  python3 ../scripts/verify_result.py
  ```

- Build option description.

  | Option | Value | Description |
  |--------|-------|-------------|
  | `CMAKE_ASC_RUN_MODE` | `npu` (default), `sim` | Run mode: NPU execution or NPU simulation. |
  | `CMAKE_ASC_ARCHITECTURES` | `dav-3510` | NPU architecture. |

- Execution result.

  A successful run prints:

  ```text
  basic_arithmetic_tensor_api executed successfully.
  test pass! verified abs for int8, int16, half, int32, and float.
  ```
