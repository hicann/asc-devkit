# Data Reorder Tensor API Sample

## Overview

This sample demonstrates the experimental register Tensor API `asc::te::experimental::deinterleave`. It reads two `float` inputs, each containing 256 elements, deinterleaves the data in two register tensors, and writes the results to two outputs.

## Supported Products

- Ascend 950PR/Ascend 950DT


## Sample Description

The sample processes two input tensors, `src0` and `src1`, each with shape `[16, 16]` and data type `float`. It loads corresponding data into register tensors, calls `asc::te::experimental::deinterleave`, and stores the two result register tensors to `dst0` and `dst1`.

| Item | Name | Shape | Data Type |
| --- | --- | --- | --- |
| Input | `src0` | `[16, 16]` | `float` |
| Input | `src1` | `[16, 16]` | `float` |
| Output | `dst0` | `[16, 16]` | `float` |
| Output | `dst1` | `[16, 16]` | `float` |
| Kernel Function | `data_reorder` | - | - |

## Sample Implementation

1. Create GM and UB Tensor objects for the two inputs and two outputs by using `asc::te::make_tensor`, `asc::te::make_mem_ptr`, and `asc::te::make_frame_layout`.
2. Use `asc_lock` and `asc_unlock` to manage the MTE2 pipeline, and call Tensor API `copy` to move both inputs from GM to UB.
3. Lock the Vector pipeline. For every register-width chunk, load both UB tensors with `asc::te::experimental::load`, call `asc::te::experimental::deinterleave`, and write the two results back to UB with `asc::te::experimental::store`.
4. The number of elements processed by each register operation is calculated as `asc_get_vf_len() / sizeof(DataType)`. The kernel repeats this operation until all 256 elements have been processed.
5. Use `asc_lock` and `asc_unlock` to manage the MTE3 pipeline, and call Tensor API `copy` to move both output tensors from UB to GM.
6. The host program launches `data_reorder` with `<<<>>>`, writes the output files, and compares them with the golden data generated by `scripts/gen_data.py`.

## Core Interface

### asc::te::experimental::deinterleave

```cpp
template <typename T>
__simd_callee__ inline reg_pair<T> deinterleave(reg_tensor<T> src0, reg_tensor<T> src1);
```

This API deinterleaves elements from two register tensors and returns the two result register tensors as `reg_pair<T>`.

## Build and Run

Run the following commands in this sample directory:

```bash
mkdir -p build && cd build
cmake -DCMAKE_ASC_ARCHITECTURES=dav-3510 -DCANN_ASC_USE_EXPERIMENTAL=ON ..
make -j
python3 ../scripts/gen_data.py
./demo
```

To run the sample in NPU simulation mode, add `-DCMAKE_ASC_RUN_MODE=sim` to the CMake command:

```bash
cmake -DCMAKE_ASC_RUN_MODE=sim -DCMAKE_ASC_ARCHITECTURES=dav-3510 -DCANN_ASC_USE_EXPERIMENTAL=ON ..
```

When switching the run mode, clear the CMake cache in the `build` directory before reconfiguring the project.

### Build Options

| Option | Available Values | Description |
| --- | --- | --- |
| `CMAKE_ASC_RUN_MODE` | `npu` (default), `sim` | Operator execution mode: NPU execution or NPU simulation. |
| `CMAKE_ASC_ARCHITECTURES` | `dav-3510` | NPU architecture. `dav-3510` corresponds to Ascend 950PR/Ascend 950DT. |
| `CANN_ASC_USE_EXPERIMENTAL` | `ON` (required), `OFF` (default) | Enables experimental ASC APIs. |
