# Composite Compute Sample Implemented with Tensor API

## Overview

This sample demonstrates the register composite compute API `asc::te::experimental::fma` with Tensor API. It covers `half` and `float`. Each type has three 64-element input vectors, and the output stores `a * b + c`.

## Supported Products

- Ascend 950PR/Ascend 950DT

## Sample Description

- Sample function:
  The sample performs fused multiply-add on three input Tensors:

  ```text
  output_i = input_a_i * input_b_i + input_c_i
  ```

- Sample implementation:

  - Kernel implementation

    1. Create Tensor objects on GM and UB by using `asc::te::make_tensor`, `asc::te::make_mem_ptr`, and `asc::te::make_frame_layout`.
    2. Move input data from GM to UB by using `asc::te::make_copy` and `asc::te::copy`.
    3. Load the three input Tensors as `reg_tensor` by using Tensor `load`, and use `make_mask<mask_pattern::vl64, T>()` to select 64 elements.
    4. Call `asc::te::experimental::fma(input_a, input_b, input_c)` and store the result back to UB by using Tensor `store`.
    5. Move the result from UB back to GM by using `asc::te::copy`.

  - Invocation implementation

    The host program reads input files generated by `scripts/gen_data.py`, invokes the kernel function with `<<<>>>`, saves output files after execution, and verifies them with `scripts/verify_result.py`.

## Core Interface

### asc::te::experimental::fma

```cpp
template <typename T>
__simd_callee__ inline decltype(auto) fma(
    const reg_tensor<T>& src0, const reg_tensor<T>& src1, const reg_tensor<T>& src2);
```

This API performs fused multiply-add on three input `reg_tensor` objects and returns a `reg_tensor` with the same element type.

## Build and Run

Run the following steps in the sample root directory to build and execute the sample.

- Configure environment variables.

  Configure environment variables based on the CANN development toolkit installation path.

  ```bash
  source ${install_path}/cann/set_env.sh
  ```

- Run the sample.

  ```bash
  mkdir -p build && cd build
  cmake -DCMAKE_ASC_ARCHITECTURES=dav-3510 -DCANN_ASC_USE_EXPERIMENTAL=ON ..
  make -j
  python3 ../scripts/gen_data.py
  ./demo
  python3 ../scripts/verify_result.py
  ```

- Build option description.

  | Option | Value | Description |
  |--------|-------|-------------|
  | `CMAKE_ASC_RUN_MODE` | `npu` (default), `sim` | Run mode: NPU execution or NPU simulation. |
  | `CMAKE_ASC_ARCHITECTURES` | `dav-3510` | NPU architecture. |
  | `CANN_ASC_USE_EXPERIMENTAL` | `ON` (required), `OFF` (default) | Enables experimental ASC APIs. |

- Execution result.

  A successful run prints:

  ```text
  composite_compute_tensor_api executed successfully.
  test pass! verified fma for half and float.
  ```
