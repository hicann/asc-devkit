# Profiling Sample Introduction

## Overview

This sample demonstrates how to collect performance data using Profiling tools.

## Sample List

| Directory Name | Description | Supported Products |
| -------------- | ----------- | --- |
| [msprof](./msprof) |  This sample uses Add as the workload to demonstrate how to collect on-device performance data with `msopprof`. | Ascend 950PR&950DT products<br>Atlas A3 products<br>Atlas A2 products |
| [torch_library_report_tensor](./torch_library_report_tensor) |  This sample demonstrates how to integrate Profiling in a `torch.library` custom operator call and display input/output Tensor shape, data type, and format information in msprof results. | Ascend 950PR&950DT products<br>Atlas A3 products<br>Atlas A2 products |
